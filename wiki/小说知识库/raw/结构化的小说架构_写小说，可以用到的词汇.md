## 词汇使用技巧

### 1. 词汇组合

```
基础魔法词 + 元素词 = 新魔法
例：火球术 + 冰 = 冰冻火球（自相矛盾但有趣）

能力词 + 场景词 = 新能力
例：跳跃 + 水下 = 水下跳跃（突破限制）
```

### 2. 词汇等级

- **普通**：常见，可替代
- **稀有**：不常见，有一定价值
- **传奇**：非常不常见，稀有
- **神话**：几乎不存在，传说级别

### 3. 词汇命名规则

```
基础名 + 修饰词 + 等级
例：火球术 → 冰焰火球术 → 神级冰焰火球术
```
