# 原创小说 · 极简精华笔记

本文档是一份高度浓缩的小说创作实战笔记，提炼了一套可复制的成长故事创作公式。核心主张是：**有缺陷的主角 + 可探索的规则体系 + 颠覆性身份真相 + 高维力量干预 + 坚实情感内核 = 好的成长故事**。

文档包含四大创作法则（角色设计、成长路径、情节推进、情感关系）、三句话心法以及一个可操作的章节自检清单。其价值在于将抽象的小说创作理论转化为具体、可执行的工具，适合新手快速上手，也适合老手作为创作检查参考。

## 核心创作公式

有缺陷的主角 + 可探索的规则体系 + 颠覆性身份真相 + 高维力量干预 + 坚实情感内核 = 好的成长故事

## 四大创作法则

1. **角色设计：缺陷即特色** — 起点是“被嘲笑的缺陷”，而非“天赋”。缺陷是独特优势的钥匙。给主角一个超越“变强”的情感动力（一个约定，守护某人）。
2. **成长路径：规则高于蛮力** — 成长核心是发现并利用世界的隐藏规则/漏洞，而非单纯堆力量。极致专精能触发质变。绝境推理比力量爆发更显魅力。
3. **情节推进：颠覆与干预** — 制造身份反转；引入高层凝视（系统、GM、至高组织），将冲突拉升到与“世界规则”对抗的层面。
4. **情感关系：约定与守护** — 互补型搭档能深化羁绊。

## 三句话心法

1. 起点要“歪”：主角因一个被嘲笑的缺陷，做出一个反常规选择。
2. 成长要“探”：他靠探索世界的隐藏规则来变强，而非机械升级。
3. 冲突要“升”：最终，他揭示颠覆性的身份，引来更高维度的注目。

## 自检清单

一章写完，快速检查：
1. 主角动了什么？（目标→阻碍→行动→结果）
2. 主角变了吗？（能力/认知/情绪）
3. 展示了什么新规则？（系统/机制/逻辑）
4. 情感推力是什么？（约定/守护/不服）
5. 结尾有钩子吗？（悬念/伏笔/新问题）
