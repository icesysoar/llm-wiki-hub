# 角色扮演

角色扮演是一种提示词工程技术，通过让模型扮演特定角色，获得更专业、更贴合场景的输出。

## 基本格式

```
你是一位资深的[角色]。请[任务描述]。
```

### 示例

```
你是一位资深的数据科学家。请分析以下数据，并给出业务建议：
[数据]
```

```
你是一位经验丰富的英语老师。请纠正以下句子中的错误：
[句子]
```

## 应用场景

### 1. 专业咨询

让模型扮演领域专家：
- 医生、律师、工程师
- 金融分析师、心理咨询师

### 2. 创意写作

让模型扮演虚构角色：
- 小说人物
- 历史人物
- 特定职业角色

### 3. 教学辅导

让模型扮演教师：
- 数学老师、英语老师
- 编程导师

## 实践建议

1. **角色定义清晰**：明确角色的专业背景、经验、视角
2. **提供上下文**：说明任务场景、目标受众
3. **引导输出格式**：指定回答的风格、深度、格式

## 与提示词工程的关系

角色扮演是 提示词工程 的高级技巧之一，与以下技术可组合使用：
- Chain-of-Thought - 让角色展示推理过程
- Few-shot学习 - 提供角色行为的示例
