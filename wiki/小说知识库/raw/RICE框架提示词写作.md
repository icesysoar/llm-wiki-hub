# RICE框架提示词写作

Prompt Engineering（提示词工程），通俗讲就是：「如何跟 AI 说话，才能让它明白你要什么」。

## 万能公式：RICE 框架

写高质量 Prompt，记住这四个要素——凑成「RICE」（大米饭），饭不可一日不吃，Prompt 不可不会写。

### R - Role（角色）

告诉 AI 它是谁。「你是一位 Python 专家」比「帮我写代码」有效 10 倍。

### I - Input（输入）

你的具体需求，越详细越好。把你能想到的条件都说出来。

### C - Context（背景）

使用场景是什么？给谁用？什么语言/框架/环境？

### E - Expectation（期望）

输出格式要求：要代码还是文字？要注释吗？要几个版本？

## RICE 框架实战示例

```
【R - 角色】你是一位经验丰富的 Python 后端工程师。
【I - 输入】帮我写一个用户登录验证函数。
  输入：用户名（字符串）和密码（字符串）
  验证规则：用户名 3-20 位字母数字，密码至少 8 位且包含大小写字母和数字
【C - 背景】项目是 Flask Web 应用，用户数据存在 MySQL 数据库，
  已有 User 模型类，字段有 username 和 password_hash
【E - 期望】返回完整的函数代码，要有参数校验、错误提示信息、
  代码注释，并说明需要安装哪些依赖包
```

## 3 个让 AI 立刻变聪明的技巧

### 技巧 1：给例子（Few-shot Prompting）

与其费力解释，不如直接给 AI 看例子。AI 的本质是「找规律」，你给几个示例，它立马懂你的意图。

```
# 不给例子（AI 只能猜）
prompt = "帮我把这些词语转成编程变量名"

# 给例子（AI 秒懂规则）
prompt = """
把以下词语转换为 Python 变量名（下划线命名法）：
例子：
用户名 → user_name
订单总价 → order_total_price
是否登录 → is_logged_in

现在转换：
商品库存数量 → ?
最大重试次数 → ?
"""
```

### 技巧 2：让 AI 先思考再回答（Chain of Thought）

复杂问题直接问，AI 容易给错答案。加一句「先一步步分析，再给出结论」，正确率提升 50%以上。

```
prompt = """
下面这段 Python 代码有 Bug，请：
1. 先逐行分析代码逻辑
2. 找出所有可能的问题
3. 最后给出修复后的完整代码

代码：
def calculate_average(numbers):
    total = 0
    for n in numbers:
        total += n
    return total / len(numbers)
"""
```

### 技巧 3：角色扮演解锁专家模式

「你是一个……」这个开头，威力比你想象的大得多。AI 被赋予角色后，会自动调整回答的专业度、语气和视角。

```
# 普通模式
"帮我 review 这段代码"
# → 一般性建议，平平无奇

# 专家模式
"你是 Google 的资深工程师，代码审查经验丰富，
请以严格的代码审查标准 review 以下代码，
重点关注：性能问题、安全漏洞、代码可读性"
# → 专业细致，指出你根本没想到的问题

# 教学模式
"你是一位耐心的编程老师，面向完全零基础的学生，
请用生活化的比喻解释什么是递归"
# → 用俄罗斯套娃、镜子等比喻讲得贼清楚
```

## 写 Prompt 的 4 大死亡禁忌

### 禁忌 1：太模糊

「写个好的函数」——「好」是什么意思？AI 根本不知道你的标准是什么。

### 禁忌 2：太长

一个 Prompt 塞 10 个需求——AI 注意力有限。需求多请拆分，一次一个任务。

### 禁忌 3：只问一次

AI 给错了就放弃——Prompt 是可以迭代的！第一次给出基础版，然后追加「优化 XX 部分」「增加 XX 功能」，逐步逼近目标。

### 禁忌 4：不验证

AI 说什么信什么——AI 会「一本正经地胡说八道」（业界称之为幻觉）。代码要跑一遍，数据要核实一遍，AI 是助手不是上帝。

## 今日速查：Prompt 秘籍

- **RICE 框架**：Role 角色 + Input 输入 + Context 背景 + Expectation 期望
- **给例子**：Few-shot 学习，AI 秒懂你的意图
- **先思考**：Chain of Thought，复杂问题准确率倍增
- **角色扮演**：指定 AI 的身份，解锁专家级回答
- **迭代优化**：第一次给基础版，逐步追加细化

## 核心理念

Prompt 是写给 AI 的需求文档。

你写需求文档越清楚，程序员越好做事；
你的 Prompt 越清晰，AI 越能给你满意的答案。

这件事和技术无关，和「把话说清楚」有关。
