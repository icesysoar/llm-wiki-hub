# 投稿变现

> 把文字变成收入

---

## 核心结论

1. **选择适合的平台** - 根据题材和风格匹配
2. **稳定更新** - 日更2000-4000字是基本
3. **研究榜单** - 学习同类型爆款

---

## [[AI推理]] 提炼

### 变现的优先级

**新手常见误区：**
- 一上来就想月入过万
- 不研究市场闭门造车
- 更新不稳定

**正确路径：**
1. 先写完一本（不管成绩）
2. 研究市场，知道什么受欢迎
3. 第二本开始针对性创作
4. 积累读者和经验

**AI理解：**
变现的前提是"有人看"。新人要把精力放在"怎么让读者愿意看"上，而不是"怎么赚钱"上。

## 变现方式

### 1. 订阅收益

```
· 付费章节订阅
· 按千字计算稿费
· 平台和作者分成（通常5:5或6:4）
· 大神可谈更高分成
```

### 2. 全勤奖

| 平台 | 日更要求 | 月全勤奖励 |
|------|----------|------------|
| 番茄 | 4000字+ | 1000-3000元 |
| 起点 | 3000字+ | 600-2000元 |
| 飞卢 | 6000字+ | 2000-5000元 |

### 3. 平台签约

签约后权益：
- 推荐资源倾斜
- 全勤奖励翻倍
- 完本奖励
- 版权优先权

### 4. IP改编

```
· 影视改编
· 游戏改编
· 有声书改编
· 漫画改编
· 海外版权
```

## 签约攻略

### 编辑看什么

1. **开头是否吸引人** - 前3万字定生死
2. **人物是否有记忆点** - 名字好记吗？有特色吗？
3. **节奏是否明快** - 不要废话太多
4. **有无明显毒点** - 绿帽、圣母、无脑等

### 新手建议

```
1. 选择适合的平台（根据题材和风格）
2. 研究榜单（看同类型作品怎么写）
3. 保持稳定更新（日更2000-4000字）
4. 注意前3万字（编辑主要看这里）
```

## 质疑

1. **前提假设是什么？**
   - 新人能靠写小说赚钱？确实可以，但需要时间

2. **有没有反例？**
   - 有人第一本就爆红
   - 但这是小概率事件

3. **可靠性如何？**
   - 认真写，月入几千是可以期待的
   - 月入过万需要实力+运气

## 常见问题

| 问题 | 答案 |
|------|------|
| 新手该日更多少字？ | 建议2000-4000字，稳定比数量重要 |
| 被拒稿怎么办？ | 分析原因，继续投稿或换个平台 |
| 要不要写大纲？ | 强烈建议写，尤其是长篇 |
| 如何提高？ | 多看、多写、多分析爆款作品 |

<CONFLICT>
矛盾：专注vs多平台
- 观点A：专注一个平台，深耕积累读者
- 观点B：多平台发布，最大化曝光
- 结论：新人建议专注一平台，有积累后多平台分发
</CONFLICT>
