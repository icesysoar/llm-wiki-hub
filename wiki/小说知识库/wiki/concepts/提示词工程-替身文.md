# 提示词工程-替身文

## 核心结论

1. **身份错位冲突**：主角被迫成为他人的"替身"，在金钱需求和自我认同之间挣扎
2. **情感错位发展**：替身逐渐爱上对方，却发现对方只把自己当作替身
3. **雪花写作法深化**：用雪花写作法从多角度展开角色背景和心理

## 角色架构

### 核心角色设定

| 角色 | 特点 |
|------|------|
| **替身主角** | 普通家庭出身，经济困难，渴望认可 |
| **"正主"** | 富商/权贵，有无法忘怀的过去 |
| **白月光** | 不在场但影响一切的原型人物 |

### 角色心理

- **渴望认可**：希望通过努力改变现状
- **身份矛盾**：需要金钱 vs 不愿失去自我
- **情感错位**：爱上对方 vs 被当作替身

## 五步工作流程

1. **确定主题** → 故事主题和基本情节
2. **雪花展开** → 从不同角度展开角色背景
3. **心理细化** → 角色心理活动和情感变化
4. **情节构建** → 每个决策和事件的必然性
5. **审视调整** → 确保每个部分紧密相连

## 情感发展轨迹

```
被迫接受 → 逐渐适应 → 产生感情 → 发现真相 → 痛苦挣扎 → 离开 → 独立成长 → 真心和解
```

### 六阶段故事

| 阶段 | 内容 |
|------|------|
| **被迫接受** | 因经济原因成为替身 |
| **情感变化** | 在关心下逐渐产生感情 |
| **真相揭露** | 发现自己只是替身 |
| **痛苦挣扎** | 内心充满痛苦和矛盾 |
| **身份暴露** | 意外揭露真实身份 |
| **独立成长** | 离开后用自己的努力追求幸福 |

## 输出框架

- **角色深度分析**：过去、梦想、恐惧和动机
- **情节细节构建**：每个事件的因果关系
- **情感发展轨迹**：角色情感的起伏和转变
- **故事逻辑检验**：确保每个环节合理且必要

## [[AI推理]]

替身文体现了**身份焦虑**的深层主题：

- **自我价值**：替身的核心冲突是"我是谁"的身份危机
- **爱情本质**：对方爱的是"我"还是"我的替身"？
- **独立成长**：最终的主题是自我价值的实现

这种类型需要作者既是**心理学家**（理解身份焦虑），又是**情感设计师**（设计虐心桥段），还是**成长叙事者**（设计独立弧线）。

## 创作建议

### 角色设计

- 为每个角色创建详细背景故事
- 思考关键决策如何反映内心世界
- 利用内心独白展现心理活动

### 情节设计

- 设计角色之间的对话和互动
- 在情节中设置意外和转折
- 确保每个事件都有因果关系

### 情感把控

- 细腻描写情感变化
- 痛苦和挣扎要有层次
- 结局要有成长和和解

## <CONFLICT> 潜在矛盾

- **虐心 vs 读者承受**：太虐可能让读者弃文
- **替身 vs 独立**：最终和解可能削弱独立主题
- **现实 vs 理想化**：结局太理想化可能失去真实感
