# 提示词工程-女频虐文

## 核心结论

1. **生活真实感**：使用贴近生活的词汇（婆婆、家庭、吵架），让读者产生共鸣
2. **情感极致化**：运用夸张修辞和感官描写，将痛苦、绝望推向极致
3. **理想化反转**：结局违背真实生活，提供现实中不常见的理想结局

## 语言技巧

### 专属词汇

| 类型 | 示例 |
|------|------|
| **生活化词汇** | 婆婆、公公、家庭、吵架 |
| **情感色彩词汇** | 痛苦、绝望、心碎 |
| **夸张修辞** | 悲痛欲绝、肝肠寸断 |
| **感官描写** | 眼泪潸然落下、心如刀绞 |
| **程度副词** | 非常、极度、痛彻心扉 |

### 专属句式

- 简单通顺句式，避免长难句
- 感叹句、反问句表达情感
- 排比句式增加节奏感（"日复一日，年复一年"）
- 断句突出转折（"她哭了。她终于崩溃了"）
- 短小精悍的句子强调反转
- 首尾呼应增加连贯性

## 核心约束

- ✅ 故事结局要违背真实生活（理想化）
- ✅ 主线具备起承转合的连贯性
- ✅ 注意细节描写，让故事生动真实
- ✅ 插入人物对话，揭示个性与冲突
- ✅ 结局要合理，前后呼应
- ❌ 避免过于现实的悲剧结局

## 故事结构

```
导语 → 起章 → 承接 → 付费点 → 转折 → 合
```

| 部分 | 功能 |
|------|------|
| **导语** | 引入背景，建立情感基调 |
| **起章** | 虐心事件开始 |
| **承接** | 痛苦升级，读者情绪累积 |
| **付费点** | 关键悬念，引导继续阅读 |
| **转折** | 局势逆转，开始反击 |
| **合** | 理想化结局 |

## [[AI推理]]

女频虐文体现了**情感宣泄叙事**：

- **痛苦共鸣**：读者通过角色的痛苦获得情感释放
- **极致体验**：夸张修辞让情感体验更强烈
- **补偿心理**：理想化结局补偿现实中的不公

这种类型需要作者既是**情感操控师**（精准把控读者情绪），又是**语言艺术家**（运用修辞增强感染力），还是**节奏大师**（虐与爽的交替）。

## 创作建议

### 情感设计

- 设计让人心疼落泪的桥段
- 情感起伏要合理，不能一味虐
- 虐心阶段要充分，为后续反转蓄力

### 人物塑造

- 塑造个性鲜明的人物形象
- 刻画细腻入微的人物关系
- 人物行为要有合理动机

### 节奏控制

- 懂得控制节奏，留下悬念
- 虐与爽交替，保持读者兴趣
- 通过细节描写增强情感深度

### 反转设计

- 设计合理的故事反转
- 满足读者的期待
- 结局要前后呼应
