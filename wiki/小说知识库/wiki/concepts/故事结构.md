# 故事结构

> 掌握叙事骨架，让故事流畅完整

---

## 核心结论

1. **三幕式** - 建置→对抗→解决的大框架
2. **起承转合** - 打破平衡→升级→反转→新平衡
3. **节奏规划** - 提前规划高潮和转折位置

---

## [[AI推理]] 提炼

### 结构的本质

**AI理解：**
故事结构不是"模板"，而是"经验总结"。它告诉你读者喜欢怎么听故事。

**为什么需要结构？**
- 人脑喜欢模式（Pattern）
- 冲突→解决→新冲突→新解决 是最自然的叙事模式
- 没有结构的故事会让读者"不知道在讲什么"

## 三幕式详解

### 结构图示

```
第一幕（10-25%）        第二幕（50-75%）           第三幕（10-25%）
┌─────────────┐    ┌─────────────────────────┐   ┌────────────┐
│   建置      │    │         对抗            │   │   解决     │
│             │    │                         │   │            │
│ ·日常建立   │    │ ·中点转折               │   │ ·最终对决  │
│ ·人物介绍   │ →  │ ·更大障碍               │ → │ ·问题解决  │
│ ·核心冲突   │    │ ·多次失败               │   │ ·新日常    │
│ ·决定行动   │    │ ·信念动摇               │   │            │
└─────────────┘    └─────────────────────────┘   └────────────┘
```

### 各幕功能

| 幕 | 占比 | 核心任务 | 问自己 |
|----|------|----------|--------|
| 第一幕 | 10-25% | 建置世界/人物/冲突 | 读者知道这是什么样的故事吗？ |
| 第二幕 | 50-75% | 主角尝试解决问题 | 主角在努力吗？障碍够大吗？ |
| 第三幕 | 10-25% | 最终解决 | 结局合理吗？ |

## 起承转合详解

### 正确理解

| 阶段 | 传统理解 | 正确理解 |
|------|----------|----------|
| 起 | 开头介绍 | 突发事件打破平衡 |
| 承 | 发展推进 | 连锁反应不断升级 |
| 转 | 高潮 | 最大反转/危机 |
| 合 | 结尾 | 建立新的平衡 |

### 关键点

- **起** 不是"介绍"，而是"打破"
- **承** 不是"平推"，而是"升级"
- **转** 不是"高潮"，而是"意外"
- **合** 不是"结束"，而是"改变"

## 节奏规划

### 高潮分布

| 类型 | 频率 | 强度 |
|------|------|------|
| 小高潮 | 每3-5章 | 局部胜利/小爽点 |
| 中高潮 | 每10-20章 | 阶段胜利/打脸 |
| 大高潮 | 每50-100章 | 世界观级别冲突 |

### 避免的问题

- [ ] 前紧后松？（开头太精彩，后面疲软）
- [ ] 前松后紧？（开头平淡，后面突然精彩）
- [ ] 高潮重叠？（连续大高潮导致疲劳）
- [ ] 没有缓冲？（高潮之间没有喘息）

## 质疑

1. **前提假设是什么？**
   - 读者喜欢这种节奏？基于大量成功作品验证

2. **有没有反例？**
   - 某些实验性文学确实打破结构
   - 但不适合商业网文

3. **可靠性如何？**
   - 商业小说领域高度可靠

## 实战：快速搭建结构

```
1. 写一句话总结（这个故事讲什么？）
       ↓
2. 确定开头状态（主角的"日常"是什么？）
       ↓
3. 确定结尾状态（主角最后改变了什么？）
       ↓
4. 设置中点（从哪里开始转折？）
       ↓
5. 填充起承转合（每个阶段2-3个关键事件）
       ↓
6. 检查节奏（高潮间隔均匀吗？）
```

## 节奏控制技巧（新增）

来自raw/小说节奏控制技巧.md的增强编译内容：

### 什么是好节奏

好节奏不是一味快，也不是一味慢。而是像蹦迪一样，有起有落，有高潮有缓冲。

读者追更的动力，来自「爽点」的密集程度。

### 把握节奏的6个秘诀

1. **把握住核心**
   - 明确小说核心目的（主角目标或核心谜题）
   - 偏离主线的描写不需要着重描写

2. **关键时刻，果断加速**
   - 高潮、冲突爆发、关键信息揭示时节奏必须快
   - 多用短句、短段落，减少修饰，直击核心

3. **情感挖掘，慢下来**
   - 情感爆发或转变时慢下来增加细节
   - 让"慢"成为有目的的蓄力，而不是拖沓

4. **限定场景**
   - 搞清楚场景要达到什么效果
   - 达到目标后收尾，不要"恋战"

5. **别让配角抢了戏**
   - 主角的感知和反应是读者代入的关键
   - 描写环境时始终关联主角

6. **描写不要拖沓**
   - 多用精准、强画面感的动词
   - 让每一个细节都"动"起来

### 三个狠招拿捏节奏

| 方法 | 核心要点 | 示例 |
|------|----------|------|
| **快慢结合** | 该快则快，该慢则慢 | 紧张调查快，回忆情感慢 |
| **冲突-解决单元** | 每章或每几章一个小单元 | 冲突→解决→新冲突→新解决 |
| **控制信息密度** | 边讲故事边给信息 | 避免开篇大段设定 |

### 节奏控制要点总结

| 场景类型 | 节奏处理 | 写作技巧 |
|---------|---------|---------|
| 高潮冲突 | 快 | 短句、短段落、少修饰、重动作 |
| 情感爆发 | 慢 | 细节描写、感官刻画、心理活动 |
| 信息传递 | 适中 | 跟随剧情逐步释放 |
| 日常过渡 | 快或省略 | 无关主线则简写或跳过 |

[[AI推理]] 节奏控制的本质是「注意力管理」。读者的注意力是有限的资源，作者需要决定在哪里投入重笔墨（慢），在哪里快速推进（快）。好的节奏让读者既不会疲劳，也不会无聊。

<CONFLICT>
矛盾：节奏统一性
- 观点A：每章必须留钩，保持高密度
- 观点B：需要缓冲章节，让读者喘息
- 结论：大高潮之间需要小高潮和缓冲，形成波浪式节奏
</CONFLICT>
