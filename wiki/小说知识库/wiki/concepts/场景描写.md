# 场景描写

> 用文字构建世界

---

## 核心结论

1. **三要素构成** - 人物+事件+环境
2. **服务剧情** - 不要为描写而描写
3. **五感描写** - 视觉/听觉/嗅觉/味觉/触觉

---

## [[AI推理]] 提炼

### 场景描写的目的

**AI理解：**
场景不是"装饰"，而是"沉浸"。好的场景描写让读者"看见"画面，"感受"氛围，"参与"剧情。

**常见错误：**
- 大段大段的环境描写，读者直接跳过
- 场景和剧情毫无关联
- 场景缺乏特色，和其他场景没区别

**正确做法：**
- 每个场景只描写最关键的3-5个细节
- 这些细节要和剧情/人物/情绪相关
- 用细节暗示而非直接说明

## 场景描写的构成

### 三要素
- **人物** - 谁在场
- **事件** - 发生什么
- **环境** - 在哪里

### 示例

❌ 流水账：
```
他们走进一个房间，房间里有一张桌子，桌上有茶杯...
```

✓ 重点突出：
```
昏暗的房间只亮着一盏油灯。
桌上那杯冷茶，已经结了一层薄冰。
——三天了，还没人来过。
```

## 常见场景类型

### 战斗场面

| 阶段 | 描写重点 |
|------|----------|
| 开打前 | 紧张气氛营造 |
| 交战中 | 动作描写、力量对比 |
| 结束后 | 结果、影响、后续 |

### 日常场面

| 要素 | 说明 |
|------|------|
| 环境细节 | 地点特征 |
| 人物互动 | 对话、动作 |
| 情感氛围 | 温馨、紧张等 |

### 会议/谈判场面

| 要素 | 说明 |
|------|------|
| 场景布置 | 地点、座位 |
| 人物心理 | 各方盘算 |
| 对话推进 | 交锋、妥协 |

## 场景转换技巧

### 常用方法

1. **时间跳转**
   ```
   "三天后..."
   "转眼已是深秋..."
   ```

2. **地点跳转**
   ```
   与此同时，另一边。
   主角踏入宗门山门时...
   ```

3. **景物过渡**
   ```
   月亮渐渐西沉，黎明的微光开始出现。
   就在这时...
   ```

### 过渡段落要点
- 简短精炼
- 承上启下
- 不要拖沓

## 场景描写的层次

| 层次 | 说明 | 特点 |
|------|------|------|
| 远景 | 交代地点、时间、氛围 | 简略、宏观 |
| 中景 | 主要人物和事件 | 详细、聚焦 |
| 近景 | 表情、动作、小物件 | 细腻、传神 |

## 五感描写

### 网文常用感官

| 感官 | 示例 | 使用频率 |
|------|------|----------|
| 视觉 | 颜色、形状、动态 | ★★★★★ |
| 听觉 | 声音、语调、静默 | ★★★★☆ |
| 触觉 | 温度、质感、疼痛 | ★★★☆☆ |
| 嗅觉 | 气味 | ★★☆☆☆ |
| 味觉 | 味道 | ★☆☆☆☆ |

### 示例

```
❌ 只用视觉：
月光洒在院子里。

✓ 五感结合：
月光冷冷地洒下来（视觉）。
虫鸣声此起彼伏（听觉）。
夜风裹挟着桂花的甜香（嗅觉）。
石凳冰凉刺骨（触觉）。
```

## 质疑

1. **前提假设是什么？**
   - 网文需要场景描写？某些快节奏文确实很少

2. **有没有反例？**
   - 某些日轻几乎没有场景描写
   - 关键看读者期待

3. **可靠性如何？**
   - 对男频玄幻/仙侠高度可靠
   - 对轻小说/日常文可以精简
