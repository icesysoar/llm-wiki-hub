# 提示词工程-悬疑小说

## 核心结论

1. **谋杀案核心驱动**：故事必须围绕谋杀案展开，以追查凶手为主线，确保叙事聚焦
2. **智力对等原则**：英雄/侦探和谋杀犯都必须聪明且足智多谋，形成智力博弈
3. **公平线索机制**：线索安排要公平，既不过于明显，也不完全隐藏，让读者有参与感

## 角色架构

### 核心角色要求

| 角色 | 要求 |
|------|------|
| **英雄/侦探** | 聪明、足智多谋，性格鲜明，让读者快速产生认同感 |
| **谋杀犯** | 同样聪明，作案动机合理，有独特之处 |
| **嫌疑人** | 多个潜在嫌疑人，每个人都有作案可能性 |

### 核心约束

- 情节发展符合逻辑，避免明显漏洞
- 叙事视角和声音一致，避免突然改变
- 结局有合理惊喜，但不完全出人意料
- 场景描写有助于营造悬疑氛围，不过于冗长

## 九步创作流程

```
1. 构思故事核心 → 确定谋杀案基本情况和动机
2. 人物设计 → 创造侦探、谋杀犯和关键角色
3. 情节规划 → 设计主要脉络和关键转折点
4. 线索安排 → 设计和安排贯穿全文的线索
5. 场景构建 → 创造充满悬疑氛围的关键场景
6. 选择叙事视角 → 决定讲述方式
7. 草拟初稿 → 按设计快速完成初稿
8. 修改完善 → 检查逻辑，完善人物和场景
9. 最终润色 → 优化语言，确保风格一致
```

## 输出框架

### 故事内容结构

1. **开场场景** - 发现案件，营造悬疑氛围
2. **主要人物介绍** - 侦探的特点描述
3. **案件概况** - 谋杀案基本情况
4. **初始线索** - 初步的、可能误导的线索
5. **潜在嫌疑人** - 多个可能的嫌疑人
6. **悬疑元素** - 埋下的悬疑伏笔

### 引导思考

输出故事后，提供思考点或问题，引导读者思考：
- 谁最有可能是凶手？
- 哪些线索是关键？
- 动机是什么？
- 还有哪些隐藏信息？

## [[AI推理]]

悬疑小说提示词体现了**推理小说的黄金法则**：

- **公平游戏原则**：读者应该和侦探拥有相同的线索
- **智力对决**：侦探与凶手的博弈是核心看点
- **氛围营造**：悬疑感不仅来自情节，更来自场景、对话、细节的层层铺垫

这种设计遵循了阿加莎·克里斯顿、柯南·道尔等经典推理作家的创作逻辑。

## 创作建议

### 开场策略

- 在开场就制造强烈悬疑氛围，吸引读者注意
- 谋杀案设计要有独特之处，避免老套

### 线索安排

- 初始线索要巧妙，既引导思考，又不过于明显
- 考虑加入看似无关但实际相关的细节

### 人物塑造

- 侦探性格要鲜明，快速建立认同感
- 嫌疑人引入要自然，每个人都有作案可能

### 场景与对话

- 利用环境营造悬疑氛围
- 对话简洁有力，反映性格并推动情节

### 结尾设计

- 留下强烈悬念，吸引继续阅读
- 结局合理但有惊喜

## <CONFLICT> 潜在矛盾

- **线索明显度**：太明显失去趣味，太隐藏让读者挫败
- ** surprise vs 公平**：结局要惊喜，但不能让读者觉得被欺骗
- **氛围 vs 节奏**：详细描写营造氛围，但可能拖慢节奏
