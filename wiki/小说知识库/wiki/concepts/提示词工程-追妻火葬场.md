# 提示词工程-追妻火葬场

## 核心结论

1. **经典套路运用**：合理运用误会、认错、囚禁、失忆等常见套路
2. **情感反转设计**：从伤害到后悔再到追回的完整情感弧线
3. **创新与平衡**：在经典套路基础上力求创新，避免情节雷同

## 角色架构

### 核心角色

| 角色 | 特点 |
|------|------|
| **伤害方** | 前期冷漠/伤害，后期后悔追回 |
| **受伤害方** | 前期隐忍/付出，后期独立/释然 |
| **第三者** | 可能是误会来源或催化剂 |

### 角色成长

- **伤害方**：冷漠 → 伤害 → 失去 → 后悔 → 改变 → 追回
- **受伤害方**：付出 → 隐忍 → 失望 → 离开 → 成长 → 释然/和解

## 五步工作流程

1. **情节构思** → 根据"追妻火葬场"特点构思框架
2. **人物设定** → 设计性格、背景和关系
3. **情感冲突设计** → 设计戏剧性转折
4. **情节细化** → 具体场景和对话
5. **审稿修改** → 确保连贯和流畅

## 常见套路

### 经典元素

| 套路 | 说明 |
|------|------|
| **误会** | 因误解导致伤害 |
| **认错** | 发现真相后后悔 |
| **囚禁** | 极端方式留住对方 |
| **失忆** | 一方失忘改变关系 |
| **重生** | 重回过去改变选择 |
| **白月光** | 第三者的介入 |

### 创新方向

- 在经典套路基础上加入新元素
- 设计多个情节转折点
- 确保情节发展符合逻辑

## 输出框架

- **情节框架**：基本情节发展和主要转折点
- **人物设定**：性格、背景和关系
- **情感冲突**：主要情感冲突和戏剧性转折
- **具体场景**：场景和对话设计

## [[AI推理]]

追妻火葬场体现了**后悔叙事**的心理机制：

- **延迟满足**：前期的虐为后期的甜蓄力
- **权力反转**：从"被需要"到"被抛弃"再到"追回"
- **成长主题**：双方都在过程中成长

这种类型需要作者既是**情感架构师**（设计虐与甜的交替），又是**套路创新者**（在经典中求新），还是**心理分析师**（理解后悔和弥补的心理）。

## 创作建议

### 情节构思

- 使用经典套路但要创新
- 设计多个转折点
- 确保逻辑合理

### 人物设定

- 明确性格特点和成长轨迹
- 设计合理的人物关系
- 考虑背景和动机

### 情感冲突

- 设计深刻的情感冲突
- 考虑解决方式
- 通过冲突展现成长

### 场景设计

- 具体的场景和对话
- 细节描写增强氛围
- 场景服务于整体情节

## <CONFLICT> 潜在矛盾

- **虐心 vs 和解**：伤害太深可能无法和解
- **套路 vs 创新**：过度套路可能显得陈旧
- **追回 vs 独立**：和解可能削弱独立主题
