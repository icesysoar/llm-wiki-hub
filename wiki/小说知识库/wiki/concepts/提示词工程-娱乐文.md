# 提示词工程-娱乐文

## 核心结论

1. **斯奈德节拍结构**：采用15节拍的故事结构，从开场画面到终场画面完整构建娱乐圈故事
2. **现实与虚构结合**：融入热播综艺、流行文化等现实元素，增加可信度和吸引力
3. **起伏跌宕的星途**：主角经历发现、崛起、膨胀、跌落、反思、回归的完整弧线

## 角色架构

### 十五节拍故事结构

| 节拍 | 内容 | 娱乐圈对应 |
|------|------|-----------|
| 1. 开场画面 | 繁华都市夜晚，主角街头卖艺 | 默默无闻的起点 |
| 2. 主题呈现 | 被制作人发现，进入娱乐圈 | 机遇降临 |
| 3. 铺垫 | 介绍背景、梦想和挑战 | 初入行业的困难 |
| 4. 推动 | 开始音乐生涯，遇到竞争对手 | 事业起步 |
| 5. 争执 | 与竞争对手冲突，内心挣扎 | 道德抉择 |
| 6. 第二幕衔接点 | 比赛获胜，受到关注 | 崭露头角 |
| 7. B故事开始 | 遇到志同道合的朋友 | 友情/爱情线 |
| 8. 游戏时间 | 事业步入正轨 | 享受成功 |
| 9. 中点 | 作品获得巨大成功，开始膨胀 | 巅峰时刻 |
| 10. 坏蛋逼近 | 竞争对手激烈打压 | 危机降临 |
| 11. 一无所有 | 丑闻中名声扫地 | 跌入谷底 |
| 12. 灵魂的黑夜 | 反思行为，意识到真正价值 | 觉醒反思 |
| 13. 第三幕衔接点 | 决定重新开始 | 重生蜕变 |
| 14. 结局 | 以独立身份回归，获得认可 | 圆满回归 |
| 15. 终场画面 | 小型音乐会，朋友和新面孔 | 温馨收尾 |

## 核心约束

- ✅ 关注热播综艺和流行文化，挖掘新素材
- ✅ 现实元素与虚构情节相结合
- ✅ 不断创新故事情节和角色设定
- ✅ 与读者保持互动，了解反馈
- ❌ 避免重复已有的成功模式

## 娱乐文要素

### 行业场景

- 选秀比赛
- 综艺录制
- 影视拍摄
- 唱片制作
- 粉丝互动
- 媒体采访

### 冲突类型

- **竞争冲突**：与对手的明争暗斗
- **道德冲突**：成功 vs 坚守原则
- **人际冲突**：友情/爱情的考验
- **自我冲突**：膨胀 vs 初心

### 成长弧线

```
默默无闻 → 被发现 → 崛起 → 膨胀 → 跌落 → 反思 → 回归
```

## [[AI推理]]

娱乐文提示词体现了**成名叙事**的完整弧线：

- **斯奈德节拍**：15个节拍确保故事结构完整
- **现实映射**：娱乐圈的真实元素增加代入感
- **道德探讨**：成功与原则的冲突是深层主题

这种类型需要作者既是**娱乐圈观察者**（了解行业规则），又是**故事结构师**（掌握节拍），还是**情感设计师**（设计起伏跌宕）。

## 创作建议

### 行业研究

- 关注热播综艺和流行文化
- 了解娱乐圈的真实运作方式
- 挖掘新的创作素材

### 角色塑造

- 主角要有明显的才华和缺陷
- 配角要有自己的目标和动机
- 反派不能太脸谱化

### 情节设计

- 现实元素与虚构情节结合
- 不断创新，避免重复套路
- 设置合理的起伏和转折

### 读者互动

- 与读者保持互动
- 了解反馈和建议
- 根据反馈优化作品

## <CONFLICT> 潜在矛盾

- **现实 vs 虚构**：太真实可能涉及真人，太虚构失去代入感
- **成功 vs 挫折**：一直成功没看点，一直挫折太压抑
- **行业细节 vs 故事性**：过多行业描写可能拖慢节奏
