# 对话描写

> 用对话推动故事、展现性格

---

## 核心结论

1. **告别"说/道"** - 用动作、神态替代
2. **对话要符合人设** - 身份决定语气
3. **控制对话长度** - 网文宜短不宜长

---

## [[AI推理]] 提炼

### 核心问题

**原始问题：**
反复滥用"说/道"类提示语，会让角色失去情绪层次，文本变得平面单薄

**AI理解：**
网文写作中，"XX说"是最省力的方式，但也是最无趣的方式。读者会自动脑补说话的语气和表情，但你什么都没给。

**进阶路径：**
1. 初级：不用"说"，用"答/问/喊/吼"
2. 中级：用动作替代提示语
3. 高级：用场景氛围替代所有提示语

---

## 方法一：动作锚定法

### 核心逻辑
用精准贴合人设与场景的动作描写，直接明确说话主体

### 优势
- 传递情绪强度
- 全程不用"说/道"
- 完成对话衔接
- 强化画面感染力

### 适用场景
- 玄幻战斗
- 情绪爆发场景
- 紧张对峙

### 示例

❌ 错误：
```
"你以为这样就能逃掉？"他说。
```

✓ 正确：
```
反派冷笑一声，踏前一步："你以为这样就能逃掉？"
```

---

## 方法二：神态刻画法

### 核心逻辑
聚焦角色微表情、眼神变化、面部神态等细节

### 优势
- 替代"XX地说"的直白情绪定性
- 让角色情绪通过细节自然流露
- 增强代入感

### 适用场景
- 内心复杂情绪
- 微妙情感变化
- 含蓄表达

### 示例

❌ 错误：
```
"对不起..."他伤心地说道。
```

✓ 正确：
```
他眼眶微红，嘴唇颤了颤，终是没说出话来。
```

---

## 方法三：情境融合法

### 核心逻辑
将对话嵌入专属场景中，用环境、氛围串联对话

### 优势
- 规避提示语重复
- 增强场景感
- 让对话更自然

### 适用场景
- 特定氛围场景
- 仪式感场合
- 特殊环境描写

### 示例

```
雨打芭蕉，夜风穿堂。
"你终究还是来了。"
"我不得不来。"
```

---

## 质疑

1. **前提假设是什么？**
   - 网文需要画面感？短视频时代确实需要

2. **有没有反例？**
   - 某些轻小说大量使用"XX说"也没问题
   - 关键是读者群体

3. **可靠性如何？**
   - 对长篇网文可靠性高
   - 短篇和轻小说可以灵活

## 实战技巧

### 提示语多样化

| 替代词 | 适用场景 |
|--------|----------|
| 答/问/喊/吼 | 不同语气 |
| 笑/怒/哭/惊/疑 | 情绪表达 |
| 叹/吟/唱 | 特殊情境 |
| 无提示语 | 默契对话 |

### 对话要符合人设

```
文化程度决定用词：
· 大学教授不会说"俺滴娘嘞"
· 农村老汉不会说"令人窒息"

性格决定语气：
· 内向者话少，常用省略句
· 外向者话多，常有感叹词

身份决定态度：
· 下属对上级用敬语
· 朋友之间随意
```

### 控制对话长度

```
· 网文对话宜短不宜长
· 长对话要分段
· 用动作和描写打断
· 每句不超过20字最佳
```

<CONFLICT>
矛盾：提示语vs无提示语
- 观点A：对话尽量不用提示语，逼格高
- 观点B：完全不用会导致读者不知道谁在说话
- 结论：看读者群体和场景，新手期用一点提示语更安全
</CONFLICT>
