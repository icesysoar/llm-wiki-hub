# 提示词工程-耽美

## 核心结论

1. **双男主情感刻画**：精准刻画两位男性角色之间的复杂情感关系
2. **情感极致表达**：运用丰富的修辞手法和感官描写，强化情感冲击力
3. **理想化结局**：结局违背真实生活，提供不常见的理想化收尾

## 语言技巧

### 词汇运用

| 类型 | 说明 |
|------|------|
| **生活化词汇** | 增强故事真实感 |
| **情感色彩词汇** | 加强情感表达 |
| **夸张修辞** | 提升文本感染力 |
| **感官描写** | 让读者感同身受 |
| **程度副词** | 强化情感强度 |

### 句式技巧

- 简单通顺句式，提高可读性
- 感叹句、反问句表达强烈情感
- 排比句式增加节奏感
- 断句技巧突出剧情转折
- 短小精悍的句子强调紧张感

## 核心约束

- ✅ 故事结局要违背真实生活（理想化）
- ✅ 主线具备起承转合的连贯性
- ✅ 注意细节描写，让故事生动真实
- ✅ 插入人物对话，揭示个性与冲突
- ✅ 结局要合理，前后呼应

## 情绪与情节掌控

### 核心能力

- 准确把握人物情绪，创作动人心弦的桥段
- 塑造立体的人物形象，刻画复杂的人际关系
- 控制故事节奏，吸引并保持读者兴趣
- 细节描写增强故事情感深度
- 设计合理的故事反转，满足读者期待

## 故事结构

```
导语 → 起章 → 承接 → 付费点 → 转折 → 合
```

## [[AI推理]]

耽美虐文提示词体现了**禁忌情感的叙事艺术**：

- **情感纯粹性**：双男主关系不受世俗约束，情感更纯粹
- **虐心极致化**：通过极致的痛苦体验增强情感冲击
- **理想化补偿**：结局的理想化是对现实不公的补偿

这种类型需要作者既是**情感细腻者**（理解复杂情感），又是**修辞大师**（运用语言增强感染力），还是**社会观察者**（理解读者心理）。

## 创作建议

### 角色塑造

- 两位男主都要有鲜明的个性
- 刻画复杂的人际关系
- 角色行为和心理变化要合理

### 情感设计

- 情感起伏要合理
- 虐心与甜蜜交替
- 情感发展要有层次

### 节奏控制

- 控制故事节奏
- 留下悬念吸引读者
- 通过细节增强情感深度

### 反转设计

- 设计合理的故事反转
- 满足读者期待
- 了解读者心理
