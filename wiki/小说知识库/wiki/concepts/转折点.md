# 转折点

> 制造期望与现实之间落差的叙事手法

---

## 核心结论

1. **定义** - 情节发展中的关键节点，改变故事走向
2. **类型** - 预期违背、信息揭露、目标改变、关系变化、环境变化
3. **作用** - 制造惊喜、推动情节、深化冲突、塑造人物

---

## 转折点的类型

| 类型 | 说明 |
|------|------|
| **预期违背** | 与读者预期相反的结果 |
| **信息揭露** | 揭露重要信息或秘密 |
| **目标改变** | 主角的目标或方向发生改变 |
| **关系变化** | 人物关系发生重大变化 |
| **环境变化** | 环境或条件发生重大变化 |

---

## 转折点的作用

1. **制造惊喜** - 打破读者预期，带来新鲜感
2. **推动情节** - 改变故事发展方向
3. **深化冲突** - 使冲突更加复杂和深刻
4. **塑造人物** - 展现人物在压力下的反应和选择

---

## 转折点设计要点

| 要点 | 说明 |
|------|------|
| **时机恰当** | 转折点应出现在情节的关键时刻 |
| **原因合理** | 转折点的发生要有合理原因 |
| **影响明确** | 转折点应有明确的影响 |
| **循序渐进** | 转折点不宜过于突然或频繁 |
