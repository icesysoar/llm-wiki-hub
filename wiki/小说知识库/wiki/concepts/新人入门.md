# 新人入门

> 从零开始写小说的核心原则

---

## 核心原则：先写起来

> 写作技巧不是在书里学来的，是在你写废的十万字里长出来的。

---

## [[AI推理]] 新人的第一步

### 你为什么想写小说？

回答这个问题：
1. 想赚钱？
2. 想表达故事？
3. 想成为作家？
4. 单纯喜欢？

**不同的目的，决定了不同的路。**

---

## 写作前的准备

### 1. 确定方向

你想写什么类型？

| 类型 | 特点 | 适合人群 |
|------|------|----------|
| 玄幻/仙侠 | 想象力丰富，升级体系 | 喜欢宏大世界观 |
| 都市 | 贴近生活，容易上手 | 新手入门推荐 |
| 穿越/重生 | 现代知识碾压 | 创意型作者 |
| 悬疑/推理 | 逻辑严密，伏笔多 | 烧脑型作者 |
| 同人 | 借力IP，粉丝基础 | 有特定爱好 |

### 2. 选择平台

根据你的类型选择：
- 男频：起点、番茄、飞卢、纵横
- 女频：晋江、起点女生网、红袖

### 3. 开始写大纲

即使你不想写，也要写！
- 至少写出故事主线
- 确定开头和结局
- 列出主要人物

---

## 写作第一天的建议

### 不要做
❌ 不要买写作课（先把书写完再说）
❌ 不要研究太多技巧（先写）
❌ 不要和成神作者比较（你才刚开始）
❌ 不要追求完美（先完成）

### 这样做
✓ 打开文档，写下第一句话
✓ 写一个烂开头
✓ 设定一个小目标（比如今天写1000字）
✓ 写完保存，然后继续写

## 写作计划建议

### 新手第一个月计划

| 周 | 目标 | 重点 |
|----|------|------|
| 第1周 | 日更1000字 | 养成写作习惯 |
| 第2周 | 日更2000字 | 找到节奏 |
| 第3周 | 日更3000字 | 稳定输出 |
| 第4周 | 完结第一个开头 | 有始有终 |

### 字数参考

| 作品类型 | 建议字数 | 说明 |
|----------|----------|------|
| 短篇 | 1-5万字 | 练手用 |
| 中篇 | 10-30万字 | 入门级 |
| 长篇 | 50-100万字 | 正常网文 |
| 超长篇 | 200万字+ | 需要大纲支撑 |

## 五问定雏形法（快速构思）

来自旧库的补充：五问法是一种通过回答五个核心问题（主角、目标、阻碍、代价、时机）来定义故事基本要素的构思方法。

### 五个核心问题

| 问题 | 说明 |
|------|------|
| **主角是谁？** | 他/她具有哪些基本特质？ |
| **目标是什么？** | 主角在故事中追求什么？ |
| **阻碍是什么？** | 实现目标的主要障碍是什么？ |
| **代价是什么？** | 如果失败，会面临什么代价？ |
| **为什么是现在？** | 故事发生的时机和背景是什么？ |

### 优势

- **高效性** - 用最少的时间获取最多的信息
- **系统性** - 覆盖故事核心要素
- **灵活性** - 适用于各种故事类型

### 使用方法

1. **快速构思** - 用最少的时间回答所有问题
2. **聚焦核心** - 确保故事元素完整
3. **迭代优化** - 在创作过程中反复审视和调整

### 8字口诀

> 主题 → 激励 → 纲 → 细 → 冲突 → 反派 → 危机 → 交替

## 新手资源

### 免费学习资源
- 各平台新人作者群
- 龙的天空论坛
- 作者后台数据

### 避免踩坑
- 不要买课！很多是割韭菜
- 不要相信"日入过万"的广告
- 不要相信"代笔""枪手"等骗局

### 最重要的一句话

```
去写。
现在就去写。
不要等准备好了。
你永远准备不好。
先写一个烂开头，
然后慢慢改。
```
