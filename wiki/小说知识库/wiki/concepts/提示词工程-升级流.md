# 提示词工程-升级流

## 核心结论

1. **情感驱动升级**：主角的能力提升与情感发展深度绑定，每次升级都伴随情感事件
2. **金手指与背景关联**：特殊能力与主角的背景故事紧密相连，增加可信度
3. **社会阶层跃升**：能力增强带动社会地位提升，打开新的故事空间

## 角色架构

### 金手指设计示例：心灵之吻

| 要素 | 说明 |
|------|------|
| **功能** | 与特定女性接吻时触发能量交换 |
| **效果** | 提升天赋或复制对方能力 |
| **触发条件** | 情感真挚、心灵相通 |
| **限制1** | 每次使用后需要恢复期 |
| **限制2** | 复制能力持续24小时后消退 |
| **限制3** | 每次只能复制一个能力 |

### 金手指与背景的关联

- 主角从小对人际关系有深刻理解
- 孤独童年和对家庭的渴望
- 心灵之吻体现对连接和理解他人的需求

## 升级路径

### 三阶段成长

```
初次觉醒 → 能力成长 → 情感发展
```

| 阶段 | 内容 |
|------|------|
| **初次觉醒** | 意外触发金手指，发现特殊能力 |
| **能力成长** | 主动寻找心灵相通的伙伴，提升能力 |
| **情感发展** | 每次提升伴随情感纠葛，推动故事 |

### 双线发展

- **爱情线**：与女性角色建立深厚情感联系
- **社会阶层线**：能力增强 → 地位提升 → 新挑战

## 核心约束

- ✅ 金手指与主角背景和动机紧密相连
- ✅ 升级过程中设置情感冲突和内心挣扎
- ✅ 利用社会关系和爱情故事增加情节深度
- ✅ 角色成长要真实可信
- ❌ 金手指不能过于强大，失去成长空间

## 输出框架

1. **角色背景故事** - 详细描述主角的过去
2. **金手指与背景关联** - 解释能力的来源
3. **升级路径** - 与情感和动机的结合
4. **爱情线影响** - 情感对角色发展的影响
5. **社会阶层提升** - 地位变化带来的新挑战
6. **连载计划** - 更新节奏和读者互动

## [[AI推理]]

升级流提示词体现了**情感化成长叙事**：

- **情感即力量**：能力提升不是冷冰冰的数值，而是与情感事件绑定
- **代价机制**：每次升级都有恢复期和限制，避免无敌
- **双线驱动**：爱情线和社会线交织，增加故事层次

这种类型需要作者既是**情感设计师**（设计情感冲突），又是**平衡师**（控制能力增长），还是**社会分析师**（设计阶层跃升）。

## 创作建议

### 金手指设计

- 使用雪花写作法创建详细的角色心理档案
- 确保金手指与背景紧密相连
- 设置合理的限制和代价

### 情感冲突

- 在升级过程中设置内心挣扎
- 每次能力提升伴随情感代价
- 爱情线要有波折，不能太顺利

### 社会阶层

- 能力增强带动地位变化
- 新阶层带来新挑战和机遇
- 展示不同阶层的生活差异

### 读者互动

- 通过社交媒体获取反馈
- 根据读者建议优化故事
- 保持稳定的更新节奏

## <CONFLICT> 潜在矛盾

- **金手指强大 vs 成长感**：太强失去成长乐趣
- **情感驱动 vs 节奏**：情感描写可能拖慢升级节奏
- **社会阶层 vs 爽感**：阶层跃升太慢可能影响爽感
