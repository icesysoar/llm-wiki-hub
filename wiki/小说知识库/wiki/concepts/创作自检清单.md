# 创作自检清单

> 评估单章故事质量的五问题框架

---

## 核心结论

1. **目标** - 主角这章做了什么？有目标、阻碍、结果吗？
2. **成长** - 他变强了吗？能力、认知、情绪有变化吗？
3. **规则** - 有没有展示游戏/世界的规则？读者看懂了吗？
4. **动机** - 他为什么坚持？情感推力是什么？
5. **钩子** - 结尾有没有钩子？读者想不想看下一章？

---

## 五问自检框架

### 问题1：主角这章做了什么？

| 子问题 | 检查点 |
|--------|--------|
| 有目标吗？ | 主角想要什么 |
| 有阻碍吗？ | 什么阻止他 |
| 行动和结果是什么？ | 做了什么，得到什么 |

### 问题2：他变强了吗？

| 成长类型 | 说明 |
|----------|------|
| 能力成长 | 实力提升、技能掌握 |
| 认知成长 | 知道新信息、理解新真相 |
| 情绪成长 | 心态变化、情感深化 |

### 问题3：有没有展示游戏/世界的规则？

| 检查点 | 说明 |
|--------|------|
| 新系统 | 展示了什么新系统、机制 |
| 世界逻辑 | 读者看懂"怎么玩"了吗 |
| 规则限制 | 边界条件清楚吗 |

### 问题4：他为什么坚持？

| 动机类型 | 说明 |
|----------|------|
| 约定 | 为了谁许下的承诺 |
| 守护 | 想保护什么人/东西 |
| 不服 | 不甘心、不认输 |

### 问题5：结尾有没有钩子？

| 钩子类型 | 说明 |
|----------|------|
| 悬念 | 留下未解之谜 |
| 伏笔 | 埋下后续引爆点 |
| 新问题 | 引发新冲突 |

---

## 使用方式

### 写完每章后自检

1. 读一遍刚写完的章节
2. 用五个问题快速评估
3. 如果某个问题答案是"否"或"模糊"，标记需要修改

### 自检优先级

| 优先级 | 问题 | 重要性 |
|--------|------|--------|
| 必须有 | 问题1：做了什么 | 核心 |
| 最好有 | 问题2：变强了吗 | 成长感 |
| 最好有 | 问题3：规则展示 | 世界观 |
| 最好有 | 问题4：动机明确 | 代入感 |
| 必须有 | 问题5：钩子 | 留存 |
