# 人物塑造

> 人物是小说的灵魂

---

## 核心结论

1. **核心人设** - 每个角色只抓一个核心特质，再配反差
2. **四件事法则** - 用行为而非旁白立人设
3. **专属动机** - 避免工具人，每个角色有自己的欲望和恐惧

---

## [[AI推理]] 提炼

### 「核心人设」公式

**公式：核心底色 + 反差 + 执念**

**核心底色（性格主轴）：**
- 外冷内热
- 野心极强
- 温柔但有底线
- 多疑谨慎

**反差（最抓人）：**
- 冷漠大佬私下怕孤单
- 温柔书生被逼能狠绝
- 圆滑小人物内心有坚守

**执念（一生想要什么）：**
- 驱动人物做出所有选择

**AI理解：**
这个公式的精髓是"矛盾"。读者喜欢的是"出乎意料又在情理之中"的角色。反差制造意外感，执念保证行为一致。

---

## 四件事立人设

### 不靠旁白介绍，用「四件事」立人设

1. **压力选择** - 他在压力下做什么选择
2. **利益反应** - 他在利益面前怎么反应
3. **强弱态度** - 他如何对待弱者和强者
4. **日常细节** - 他的习惯和小动作

---

## 动机的层次

### 三层动机结构

| 层次 | 说明 | 示例 |
|------|------|------|
| 表层动机 | 表面想要什么 | 要复仇 |
| 深层动机 | 内心真正渴望 | 被认可 |
| 隐藏动机 | 潜意识 | 证明自己值得被爱 |

---

## [[AI推理]] 工具人问题

### 什么是工具人？
- 只有功能没有人性
- 存在只是为了推动剧情
- 读者记不住

### 如何避免？
- 每个配角都要有自己的欲望和恐惧
- 即使是反派也要有合理的行为逻辑
- 给配角自己的故事线

---

## 质疑

1. **前提假设是什么？**
   - 读者需要复杂人物？网文读者可能更关注情节

2. **有没有反例？**
   - 某些爽文反派就是脸谱化工具人，效果也很好
   - 关键看目标读者群体

3. **可靠性如何？**
   - 对长篇和需要IP改编的作品高度可靠
   - 对短平快爽文，相对次要

## 实战技巧

### 快速立人设的方法

```
反派塑造：
1. 给一个可理解的动机（不一定要认同）
2. 展示他的底线（再坏也有不能做的事）
3. 给一个失败原因（为什么输给主角）

配角塑造：
1. 一个显著特征（口头禅/习惯/癖好）
2. 与主角的关系（对手/朋友/导师）
3. 自己的目标（与主角目标产生交集或冲突）
```

<CONFLICT>
矛盾：人物复杂度的平衡
- 观点A：所有人物都要立体复杂
- 观点B：主角之外可以脸谱化，重点资源给主角
- 结论：主角和核心配角需要立体，工具人可以有标签
</CONFLICT>

## 人物塑造深度方法（新增）

来自raw/人物塑造深度方法.md的增强编译内容：

### 核心人设公式

**公式：核心底色 + 反差 + 执念、软肋、底线**

| 要素 | 说明 | 示例 |
|------|------|------|
| **核心底色** | 性格主轴 | 外冷内热、野心极强、温柔但有底线 |
| **反差** | 最抓人的点 | 冷漠大佬私下怕孤单；温柔书生被逼能狠绝 |
| **执念** | 一生想要什么 | 驱动人物做出所有选择 |
| **软肋** | 最怕失去什么 | 制造情感冲突 |
| **底线** | 绝对不能碰的事 | 保证人设不崩 |

### 四件事立人设（不用旁白）

1. **做事选择** - 遇到利益、危机时怎么选
2. **待人态度** - 对亲人、对手、陌生人差别对待
3. **说话风格** - 语气、口头禅、句式固定
4. **小习惯** - 小动作、癖好、微表情（人物记忆点）

### 专属动机三要素

长篇最怕人物只为剧情服务。每个人物必须有：
- **个人目标** - 和主角不完全一样
- **过往创伤** - 性格形成的根源
- **隐藏秘密** - 支撑后续剧情和反转

### 人物成长弧线

**成长模板：** 初始状态 → 经历事件 → 观念改变 → 结局状态

**常见成长路径：**
- 天真 → 世故
- 狠绝 → 学会心软
- 自卑 → 觉醒自强
- 野心勃勃 → 幡然醒悟

**原则：** 不变的是底层底色，变的是处事方式和心态。

### 用对比衬托个性

1. **双人对照** - 一静一动、一柔一刚、一善一狠
2. **群体对照** - 不同立场、不同性格的人放在同一场景

### 网文人物塑造实用技巧

1. **主角要有明确人设标签** - 高冷/杀伐果断/善良隐忍/扮猪吃虎，标签统一
2. **配角工具人合理化** - 反派给动机，路人避免只会嘲讽
3. **给人物专属动作+口头禅** - 让角色记忆点拉满

### 避开3个大坑

1. **人设漂移** - 为了剧情强行让人物做不符合性格的事
2. **全员同款** - 所有人说话、行事风格差不多
3. **完美无缺** - 没有缺点，没有软肋，显得假

### 主角歪（特殊技巧）

"主角歪"是指主角在故事开始时拥有一个被他人嘲笑或视为缺点的特质，这个特质往往成为其独特性和故事起点的关键。

| 要素 | 说明 |
|------|------|
| **独特性来源** | 主角的"歪"特质是其区别于他人的起点 |
| **成长基础** | 这一特质往往成为主角后续成长和探索世界规则的契机 |
| **避免刻板印象** | 需要谨慎运用，避免将"歪"简单等同于负面标签 |

**应用建议：** 在创作时，应深入挖掘"歪"特质背后的原因和潜力，将其转化为推动情节发展的动力，而非仅仅作为标签。

### 人物人设填空模板

```
1. 姓名：
2. 身份：
3. 核心性格：
4. 性格反差：
5. 人生执念：
6. 最大软肋：
7. 做人底线：
8. 口头禅/小动作：
9. 过往创伤：
10. 最终成长变化：
```

[[AI推理]] 人物塑造的核心是「一致性中的变化」。人物需要有稳定的核心（执念、底色）来保证行为逻辑一致，同时需要有成长弧线来避免扁平。反差感制造记忆点，专属动机避免工具人化。

- 观点A：所有人物都要立体复杂
- 观点B：主角之外可以脸谱化，重点资源给主角
- 结论：主角和核心配角需要立体，工具人可以有标签；长篇和IP向作品需要更复杂的人物
</CONFLICT>
