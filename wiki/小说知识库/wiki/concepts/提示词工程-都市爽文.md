# 提示词工程-都市爽文

## 核心结论

1. **生活化真实感**：使用生活化词汇、丰富的感官描写，增强故事真实感
2. **情绪感染力**：利用夸张和情绪性修辞，提升文本感染力
3. **理想化结局**：故事结局要违背真实生活，提供现实中不常见的理想结局

## 角色架构

### 核心能力

- **情绪掌控**：准确把握人物情绪，创作动人心弦的桥段
- **人物塑造**：塑造立体的人物形象，刻画复杂的人际关系
- **节奏控制**：控制故事节奏，吸引并保持读者兴趣
- **反转设计**：设计合理的故事反转，满足读者期待

### 语言技巧

| 技巧 | 说明 | 示例 |
|------|------|------|
| **生活化词汇** | 增强真实感 | 日常用语、口语化 |
| **夸张修辞** | 提升感染力 | "震惊！全城轰动！" |
| **感官描写** | 让读者感同身受 | 视觉、听觉、触觉 |
| **简单句式** | 提高可读性 | 短句为主 |
| **感叹反问** | 表达强烈情感 | "这怎么可能？！" |
| **排比句式** | 增加节奏感 | 连续短句 |
| **断句技巧** | 突出剧情转折 | 关键时刻断句 |

## 核心约束

- ✅ 故事结局要违背真实生活（理想化）
- ✅ 主线具备起承转合的连贯性
- ✅ 注意细节描写，让故事生动真实
- ✅ 插入人物对话，揭示个性与冲突
- ✅ 结局要合理，前后呼应
- ❌ 避免过于现实的悲剧结局

## 六步工作流程

1. **研读知识** → 梳理关键要素，学习总结
2. **设计框架** → 故事主题、人物画像、场景、冲突
3. **确认框架** → 与用户确认设计
4. **展开创作** → 按导语、起章、承接、付费点、转折、合的顺序
5. **优化调整** → 根据反馈修改
6. **完成输出** → Markdown格式，二级标题、列表排版

## 故事结构

### 标准流程

```
导语 → 起章 → 承接 → 付费点 → 转折 → 合
```

| 部分 | 功能 | 要点 |
|------|------|------|
| **导语** | 引入背景 | 快速建立情境 |
| **起章** | 开局冲突 | 主角困境或身份揭示 |
| **承接** | 发展推进 | 冲突升级，人物关系 |
| **付费点** | 高潮前奏 | 关键悬念，引导付费 |
| **转折** | 局势逆转 | 主角翻盘，打脸反派 |
| **合** | 圆满结局 | 理想化收尾 |

## [[AI推理]]

都市爽文提示词体现了**情绪消费**的叙事逻辑：

- **现实补偿**：提供现实中难以实现的理想结局，满足读者的心理补偿需求
- **情绪宣泄**：通过"打脸"桥段让读者获得快感
- **身份投射**：主角的成功让读者产生代入感

这种类型需要作者既是**心理学家**（理解读者心理），又是**节奏大师**（把控爽点节奏），还是**社会观察者**（捕捉现实痛点）。

## 创作建议

### 开局设计

- 快速建立主角身份（隐藏的大佬/被误解的普通人）
- 设置明显的身份反差
- 引入即将被打脸的反派

### 情绪把控

- 压抑阶段要充分，为后续爆发蓄力
- 打脸要干脆利落
- 爽点要密集，保持阅读快感

### 反转设计

- 出人意料但合乎逻辑
- 前后要有呼应
- 满足读者的期待

### 语言风格

- 口语化，接地气
- 适当夸张，增强感染力
- 短句为主，节奏明快

## <CONFLICT> 潜在矛盾

- **理想化 vs 可信度**：太理想化可能失去代入感
- **夸张 vs 真实感**：过度夸张可能显得虚假
- **爽点密集 vs 审美疲劳**：持续高潮可能让读者疲惫

## 都市爽文类型

### 常见类型

- **战神归来**：隐藏身份的战神回归都市
- **赘婿逆袭**：被看不起的赘婿真实身份惊人
- **神医下山**：医术高超的主角入世救人
- **首富继承人**：平凡少年继承巨额财富

### 经典桥段

- 身份 reveal（ reveal 时刻）
- 反派嘲讽 → 主角反击
- 众人震惊
- 美女倾心
- 势力臣服
