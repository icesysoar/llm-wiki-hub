# 提示词工程-短剧脚本

## 核心结论

1. **专业分镜格式**：使用标准化的分镜脚本格式（镜头|时间|对话|画面|备注），便于拍摄执行
2. **多维度创作**：融合网络流行梗、热门领域知识（游戏、时尚、美妆等），创作有创意的短视频内容
3. **视觉化思维**：脚本不仅是文字，更要考虑拍摄角度、演员站位、动作特写等视觉元素

## 角色架构

### 核心能力

- **创意策划**：掌握各种网络流行梗，有丰富创意
- **领域知识**：游戏、时尚、服饰、健身、食品、美妆等热门领域
- **脚本创作**：专业的短视频脚本撰写能力
- **视觉思维**：考虑拍摄执行的分镜设计

### 输出框架

#### 1. 拍摄要求

| 要素 | 说明 |
|------|------|
| **演员** | 数量、性别、主配角分配 |
| **背景** | 拍摄场景要求 |
| **服装** | 演员服装要求 |

#### 2. 分镜脚本（Markdown表格格式）

| 列 | 内容 |
|----|------|
| **镜头** | 镜头编号 |
| **时间** | 00:00-00:xx |
| **对话** | 角色：对话内容 |
| **画面** | 场景切换、拍摄角度、站位、动作特写 |
| **备注** | 其他注意事项 |

## 工作流程

1. **接收主题** → 用户输入短视频主题和具体要求
2. **创意策划** → 结合流行梗和领域知识设计内容
3. **撰写脚本** → 按标准格式输出分镜脚本
4. **优化调整** → 根据反馈修改完善

## 分镜设计要点

### 画面描述要素

- **场景切换**：何时切换场景，如何过渡
- **拍摄角度**：俯拍、仰拍、平视、特写等
- **演员站位**：人物在画面中的位置关系
- **动作要求**：演员走动、表演动作
- **特写要求**：关键动作或表情的特写镜头

### 对话设计

- 按角色列出对话内容
- 格式："角色名：对话内容"
- 简洁有力，符合短视频节奏

## [[AI推理]]

短剧脚本提示词体现了**从文字到影像**的转化思维：

- **视觉先行**：写脚本时就要想象最终画面
- **节奏紧凑**：短视频要求信息密度高，每秒都要有价值
- **执行导向**：脚本不仅是创意文档，更是拍摄指导书

这种创作需要作者既是**编剧**（故事能力），又是**导演**（视觉思维），还是**制片人**（考虑执行可行性）。

## 创作建议

### 选题策略

- 紧跟热点话题和流行梗
- 结合特定领域专业知识
- 考虑目标受众的兴趣点

### 节奏控制

- 开头3秒抓住注意力
- 中间保持信息密度
- 结尾有记忆点或互动引导

### 视觉设计

- 多用特写增强代入感
- 场景切换要有节奏感
- 动作设计要清晰可执行

## <CONFLICT> 潜在矛盾

- **创意 vs 执行**：创意很好但拍摄难度大
- **信息密度 vs 理解成本**：内容太满观众跟不上
- **娱乐性 vs 专业性**：过度娱乐可能损害专业形象

## 短剧类型

### 常见类型

- **搞笑类**：利用网络梗制造笑点
- **知识类**：专业知识科普
- **剧情类**：有情节的微型故事
- **展示类**：产品/技能展示

### 时长建议

- 15秒：单一笑点或信息点
- 30秒：简单情节或3个信息点
- 60秒：完整微型故事
