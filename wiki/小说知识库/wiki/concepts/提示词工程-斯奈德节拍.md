# 提示词工程-斯奈德节拍

## 核心结论

1. **15节拍结构**：从开场画面到终场画面的完整故事结构框架
2. **精准节奏控制**：每个节拍有明确的功能和位置，确保故事节奏
3. **普适性框架**：适用于电影、小说、短剧等各种叙事形式

## 十五节拍表

| 节拍 | 功能 | 说明 |
|------|------|------|
| 1. **开场画面** | 建立世界 | 展示主角的初始状态 |
| 2. **主题呈现** | 点明主题 | 通过对话或事件暗示主题 |
| 3. **铺垫** | 介绍背景 | 家庭、工作、内心矛盾 |
| 4. **催化剂** | 打破平衡 | 改变一切的事件 |
| 5. **争执** | 内心挣扎 | 要不要踏上旅程 |
| 6. **第二幕衔接点** | 踏上旅程 | 做出决定，进入新世界 |
| 7. **B故事** | 副线开始 | 爱情/友情线 |
| 8. **游戏时间** | 享受乐趣 | 轻松有趣的阶段 |
| 9. **中点** | 虚假胜利/失败 | 表面成功但暗藏危机 |
| 10. **坏蛋逼近** | 危机加剧 | 反派/困难越来越强 |
| 11. **一无所有** | 失去一切 | 最低谷 |
| 12. **灵魂的黑夜** | 反思觉醒 | 思考为何开始 |
| 13. **第三幕衔接点** | 重新振作 | 找到真正的方法 |
| 14. **结局** | 最终对决 | 赢得胜利 |
| 15. **终场画面** | 展示变化 | 与开场画面对比 |

## 五步工作流程

1. **深入沟通** → 了解创意和需求
2. **设计大纲** → 初步故事大纲和节拍表
3. **创作初稿** → 确保每个节拍充分体现
4. **分享修订** → 根据反馈修订
5. **反复打磨** → 达到客户和市场要求

## 核心约束

- ✅ 每个节拍得到充分体现
- ✅ 节拍之间有逻辑连贯性
- ✅ 融入独特创意
- ✅ 语言专业且激发情感共鸣

## [[AI推理]]

斯奈德节拍体现了**故事结构的科学**：

- **节奏精准**：15个节拍精确控制故事节奏
- **情感弧线**：从平衡→打破→挣扎→成长→回归
- **普适框架**：适用于任何类型的故事

这种框架需要作者既是**结构师**（精准安排节拍），又是**节奏师**（把控每个节拍的比重），还是**创意者**（在框架内创新）。

## 创作建议

### 节拍设计

- 每个节拍与客户需求和市场趋势结合
- 融入独特创意
- 定期沟通确保方向正确

### 开场与结尾

- 开场画面与终场画面形成对比
- 展示主角的成长和变化
- 首尾呼应增强连贯性

### 中点设计

- 中点要有"虚假胜利"或"虚假失败"
- 暗藏危机，为后续转折铺垫
- 改变故事的方向

### 低谷与觉醒

- "一无所有"要足够痛苦
- "灵魂的黑夜"要有深度反思
- "第三幕衔接点"要自然过渡

## <CONFLICT> 潜在矛盾

- **框架 vs 创新**：严格遵循可能限制创意
- **节拍数量 vs 故事长度**：短故事可能不需要全部15个节拍
- **普适性 vs 类型特色**：不同类型可能需要调整节拍
