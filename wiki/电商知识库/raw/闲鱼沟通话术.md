# 闲鱼沟通话术与转化



> 售前建立信任 → 售中高效闭环 → 售后口碑维护。



## 五大核心原则



| 原则 | 核心 | 操作要点 |

|------|------|---------|

| **好心情** | 情绪影响决策 | 避免生硬语气，用积极语气传递正向情绪 |

| **及时** | 黄金15秒 | 30秒内回复，不让用户等待 |

| **热情** | 拉近距离 | 用"亲亲～""宝子～"替代"哦""嗯""好" |

| **礼貌** | 真诚利他 | 无错别字，设身处地为用户着想 |

| **专业** | 建立信任 | 适当多说产品差异、售后保障，善用专业术语 |



## 售前：打消疑虑（建立信任）



| 类型 | 用户疑问 | 应对话术示例 |

|------|---------|------------|

| **产品** | "是全新正品吗？" | "亲，绝对全新未拆封官方正品～ 原厂直发，不正包退！" |

| **价格** | "为什么比别家便宜？" | "闲鱼利薄，能让早让了～ 收货给个带图好评，我返您5元！" |

| **效果** | "会不会是智商税？" | "卖得火口碑不错，大家不傻～您说说使用场景，我帮您判断合不合适！" |

| **售后** | "质保多久？" | "官方质保两年，机身序列号官网可验，售后直接对接厂家！" |

| **平台** | "怕被骗怎么办？" | "我讲诚信，您看我客户评价无一差评！不正包退，您投诉我都没问题～" |



## 售中：高效闭环



- **不夸大不隐瞒**：如实告知产品情况

- **保障货款安全**：拒绝私下转账，引导平台下单

- **及时响应**：不推诿、不敷衍



## 售后：口碑维护



| 责任归属 | 应对方式 |

|---------|---------|

| **我方责任**（质量问题） | 诚恳道歉，主动提出换货/补发/退款，甚至"不用寄回" |

| **客户责任**（个人原因） | 坚持立场，礼貌说明规则，提供合理建议 |



## 刻意练习三步



1. **建模型** → 整理《标准话术库》+《产品知识库》

2. **练** → 模拟常见疑问，按五大原则练习回复

3. **反馈** → 复盘为什么这个疑问没转化，优化话术
