# 闲鱼高频FAQ



> 常见问题速查，按类别整理。



## 账号类



| 问题 | 答案 |

|------|------|

| 可以注册几个号？ | 1个身份证=3个支付宝=3个闲鱼店铺 |

| 新号还是旧号好？ | 新号适合快速起量，旧号适合深耕垂直品类 |

| 芝麻信用分不高影响大吗？ | "优秀"及以上正常运营，"极好"最佳 |

| 养号需要几天？ | 最快3天，常规1周 |

| 双开/虚拟机能用吗？ | ❌ 不建议，有违规风险 |



## 运营类



| 问题 | 答案 |

|------|------|

| 刚上架能编辑修改吗？ | ❌ 不建议！有流量的链接编辑易断流 |

| 一个品重复上架有限流吗？ | 图片文案有20%区别则不会 |

| 每天上架几个？ | 每天1-3个，间隔至少30分钟 |

| 14天无咨询怎么办？ | 果断下架 |

| 爆款能大改吗？ | ❌ 会失去流量热度，应用爆款元素重新上架新链接 |

| 低价引流好不好？ | 不建议，来的多是低质量用户 |

| 需要营业执照吗？ | 不需要 |



## 补单类



| 问题 | 答案 |

|------|------|

| 什么是补单？ | 模拟真实购买行为增加销量和评价数据 |

| 什么时候补单？ | 链接曝光低迷或需激活时 |

| 补单流程 | 浏览（货比三家）→ 想要（寒暄几句）→ 深度浏览 → 成交 |

| 低价补单可以吗？ | ❌ 会导致标签错乱，推流贪便宜用户 |



## 货源类



| 问题 | 答案 |

|------|------|

| 没有货源怎么办？ | 同行代发 / 1688找供应商 / 拼多多代发 |

| 从同行拿货可以吗？ | 可以，出几单后找同行谈代发 |

| 拼多多发货有风险吗？ | 面单和短信可能暴露来源，用无痕发货规避 |



## 售后类



| 问题 | 答案 |

|------|------|

| 买家要开发票？ | 个人卖家开不了，可要求加税点 |

| 买家到手刀怎么办？ | 收货前明确商品情况，保留发货视频，无质量问题拒绝降价 |

| 退货怎么处理？ | 质量问题我方承担运费；非质量问题买家承担 |

| 差评能删除吗？ | 联系客服可屏蔽内容，但差评率无法消除 |
