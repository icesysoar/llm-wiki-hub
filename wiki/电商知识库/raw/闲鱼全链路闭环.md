# 闲鱼全链路闭环



> 从选品到回款，7大核心环节缺一不可。



## 七步闭环



```

选品 → 上架 → 转化（咨询） → 下单 → 订单执行（供应商） → 物流发货 → 售后回款

```



| 步骤 | 核心动作 | 关键要求 |

|------|---------|---------|

| **1. 选品** | 抄爆款，高频测试 | 有"想要"数成百上千的链接 |

| **2. 上架** | 头图+标题+文案+价格+发布地 | 参考商品页核心要素 |

| **3. 转化** | 30秒内回复，热情话术 | 避免单字回复，用"亲亲～" |

| **4. 下单** | 判断是否改价，引导付款 | 平台下单，不私下转账 |

| **5. 订单执行** | 录入订单→向供应商付款→备货 | 用订单统计总表追踪 |

| **6. 物流** | 获取物流单号→闲鱼填单→同步买家 | 无痕发货（不提拼多多） |

| **7. 售后+回款** | 处理退款→引导好评→财务回款→引流微信 | 口碑维护+私域沉淀 |



## 关键原则



- **货款安全**：拒绝私下转账，引导平台下单

- **无痕发货**：下单备注"无痕发货"，不提拼多多来源

- **积极处理售后**：第一时间响应，不推诿
