# 闲鱼日常运营规范



> 每天该做什么、不该做什么，哪些操作是对的、哪些是错的。



## 每日任务清单



| 时间 | 动作 | 说明 |

|------|------|------|

| 早上 | 检查曝光 | 每天早晚各截图一次，盯住曝光增长最高的链接 |

| 任意时间 | 一键擦亮（1次） | 每天仅点一次，不要逐个擦亮 |

| 任意时间 | 上架新品 | 每天1-3个，间隔至少30分钟 |

| 随时 | 30秒内回复 | 开启消息通知，用"亲您好～"开头 |

| 晚间 | 数据复盘 | 下架14天无咨询的链接；分析咨询多的链接，提炼卖点加到主图和标题上 |



## 商品上架标准化流程



### 找图

1. 搜索小红书"商品名+实拍"

2. 选背景干净、光线好的真人图

3. 用美图秀秀加价格标签（如【19.9元包邮】）



### 写标题

**公式**：`顺丰包邮 正品保障 + 品牌/型号 + 核心品类 + 关键属性 + 场景词`



**实操**：

- 复制天猫/京东爆款标题 → 微调关键词顺序

- 或用商品页核心要素的标题整合法



### 写正文

**公式**：`产品信息 + 价格信息 + 促销信息 + 物流售后 + 个人使用感受`



**示例结构**：

```

【品名】XX

【内含】主机x1 / 充电器x1 / 数据线x1

【售后】全新包邮，7天无理由

个人使用感受（真实可信）

```



### 定价格

- 比爆款同行便宜1元

- 或用配件/二手做低价引流（价差不要太大）



### 发布

- 选择一线/省会城市（如北京/上海/杭州）

- 避开凌晨2-5点上架



## 出单后操作



| 步骤 | 操作 |

|------|------|

| 1 | 复制买家地址去1688/拼多多下单（备注无痕发货） |

| 2 | 填写物流单号到闲鱼后台发货 |

| 3 | 同步物流信息给买家 |

| 4 | 买家确认收货后引导带图好评 |

| 5 | 原链接：直接重新上架 |



无痕发货处理：下单拼多多时备注"不要放好评返现卡"或与卖家沟通"无痕发货"。



## ✅ 每天必做（正确操作）



| 操作 | 说明 |

|------|------|

| **一键擦亮** | 每天只点一次一键擦亮，不要逐个擦亮 |

| **每天上架1-3个新品** | 间隔至少30分钟，每天不超过3个 |

| **及时回复消息** | 保持在线，不错过咨询 |

| **截图对比曝光** | 每天早晚各截图一次，盯住曝光增长最高的链接 |

| **分析咨询多的链接** | 提炼卖点，加到主图和标题上 |

| **下架14天无咨询的链接** | 无论之前曝光多少，14天无咨询直接下架 |

| **固定网络环境** | 避免WIFI/流量来回切换 |



## ❌ 每天禁止（错误操作）



| 操作 | 后果 |

|------|------|

| 每天编辑再发布（多次擦亮） | 店铺权重下降 |

| 一次修改3-5个链接以上 | 限流 |

| 批量上架/下架超过5个 | 数据异常限流 |

| 一机多号/网络共享多开 | 账号关联限流 |

| 频繁降价（每天3-4次） | 影响曝光 |

| 频繁切换WIFI/流量 | 触发审核限流 |



## 链接编辑规则



| 场景 | 操作 |

|------|------|

| 新链接上架3天内 | 不要修改，等曝光自然跑 |

| 3天后看曝光决定是否优化 | 是的话用原链接图片文案重新上架新链接 |

| 爆款链接大改图片文案 | ❌ 会失去流量热度 |

| 爆款想微调 | 用爆款元素稍作修改上架新链接，老链接保留 |



## 下架规则



| 场景 | 操作 |

|------|------|

| 一天最多下架5个 | 每次间隔3分钟 |

| 爆款断货 | 3天内能补货不用下架；超过3天建议下架 |

| 爆款7天后仍未上架 | 流量需要7-15天才能恢复 |

| 链接超过14天无咨询 | 下架，优先保留高曝光高咨询的 |



## 补单操作



| 条件 | 操作 |

|------|------|

| 曝光>10000 | 补10单以上 |

| 曝光3000-10000 | 补3-5单 |

| 曝光<3000 | 不补，继续优化内容 |



- 时段：早7-9点 / 午12-14点 / 晚19-21点

- 节奏：间隔约1小时

- 当天达标当天补，隔天无效

- 仅补曝光达标的链接，曝光未达标直接下架重选



更多细节见 补单策略。



## 其他规范



| 问题 | 结论 |

|------|------|

| 多城市发布是否限流 | ❌ 不会，优先选一线城市观察效果 |

| 重复铺货是否限流 | 图片文案有20%以上区别则不会 |

| 曝光高但无咨询 | 优化主图，突出产品优势 + 解决买家问题 |

| 曝光高但浏览低 | 优化主图和标题，标题包含精准关键词 |

| 曝光比浏览低 | 系统曝光显示延迟，等待即可 |
