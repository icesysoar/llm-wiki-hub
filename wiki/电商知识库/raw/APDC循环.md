# APDC循环

APDC循环是闲鱼店群运营中用于营销策略迭代的核心方法论，四个阶段分别为：**Aim（制定）→ Perform（执行）→ Detect（测试）→ Cycle（优化）**。

该循环强调基于数据反馈持续改进运营策略，与 数据驱动测试迭代 理念相通，但 APDC 循环提供了更具操作性的迭代框架：制定目标 → 执行计划 → 测试效果 → 优化策略，往复循环。

APDC循环可应用于：
- 标题关键词优化：制定不同赛道标题策略 → 执行上架 → 检测曝光/点击数据 → 优化标题
- 营销活动：制定概念营销/实物营销组合方案 → 执行活动 → 检测转化率变化 → 优化方案
- 定价策略：制定定价方案 → 执行标价 → 检测“我想要”数量和咨询量 → 优化定价

该循环体现了“科学运营方法论”的核心——系统化、数据驱动、持续迭代，与 销量底层公式 共同构成闲鱼运营的理论基础。
