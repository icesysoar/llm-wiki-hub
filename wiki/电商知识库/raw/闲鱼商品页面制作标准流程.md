# 闲鱼商品页面制作标准流程

## 定义

闲鱼商品页面制作标准流程是一套结构化的、可重复执行的商品页面创建方法，涵盖找图、标题撰写、文案填充三个核心步骤。其目标是确保每个上架链接都具备竞争力，提升转化率。

## 第1步：找图与处理（头图是关键）

1. **打开小红书**，搜索你的商品名+“实拍”（如“护眼台灯 实拍”）。
2. 选择一张**背景干净、光线明亮**的真人实拍图。
3. **使用美图秀秀处理头图**：
   - 添加醒目标签：`【19.9元包邮】`（价格根据实际调整）
   - 补充核心卖点：`可充电｜三档调光｜送插头`

## 第2步：标题撰写（公式化操作）

**【万能标题公式】**
`[发货保障] + [核心词] + [属性词1] + [属性词2] + [场景词]`

- **示例**：`顺丰包邮 正品保障 LED护眼台灯 充电式 三档调光 宿舍家用学习灯`
- **技巧**：上架前，将标题复制到闲鱼搜索框，检查是否有大量类似结果，验证关键词热度。

## 第3步：文案撰写（直接复制填充）

```
【现货秒发】全新正品，特价XX元包邮！最后X件！

【产品详情】
材质：ABS+LED灯珠
尺寸：高30cm，底座直径15cm
功能：三档亮度可调，USB充电，续航12小时

【自用推荐】
自己在宿舍/家里用了X个月，光线很柔和，晚上看书不伤眼，续航也很顶。

【售后保障】
下单后24小时内发货！默认发XX快递，全国包邮（偏远除外）。
有任何问题随时联系，支持七天无理由，包您满意！
```

## 与现有维基的连接

- 本流程是对闲鱼商品页面优化的实操化、步骤化补充，提供了可复制的执行方案。
- 本流程中的标题公式与闲鱼文案标题黄金公式（关键词 + 稀缺感/痛点 + 优惠/场景）互补，提供了更结构化的标题组织方式。
- 本流程中的文案模板与闲鱼文案正文结构化框架（问题-解决-信任）互补，提供了更具体的填充内容。
