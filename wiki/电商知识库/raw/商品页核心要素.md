# 商品页核心要素



> 标题 + 头图 + 文案 + 标签 = 一个完整的商品页



## 标题（30字内）



**方法**：去拼多多搜商品，复制销量第一的完整标题，稍作修改。

> 结构：`商品名` + `功能1` + `功能2` + `适用人群`



## 头图（最重要！）



- **找图**：去小红书搜商品，找"种草图"——拍得好看、背景干净

- **头图必须包含**：核心卖点（如"无线便携"）+ 价格（如"19.9包邮"）

- **用美图秀秀**在图上叠加文字

- ⚠️ 严禁使用品牌官图，会被举报！



## 文案模板



```

【产品介绍】

（写清楚材质、尺寸、颜色、功能）



【价格说明】

特价XX元包邮！拍下不改价！



【实拍感受】

（自己编一段真实好评，如："自己用了半个月，榨汁很方便，清洗也简单。"）



【物流售后】

下单后48小时内发货，有问题随时联系，包售后！

```



## 发布地与标签



- **发布地**：选北上广深等大城市

- **标签**：系统自动推荐，选满就行



## 主图优化原则



- 突出核心卖点，文字放在中间显眼位置

- 不要用过多文字遮挡产品

- 参考同行主图，但不要直接复制

- 主图点击率应 ≥ 3%
