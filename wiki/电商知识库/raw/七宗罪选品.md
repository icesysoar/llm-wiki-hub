# 七宗罪选品

七宗罪选品是一种从人性弱点出发挖掘产品需求的选品方法论。它基于七宗罪（傲慢、嫉妒、暴怒、懒惰、贪婪、暴食、色欲）这一经典人性框架，为每个“罪”匹配对应的产品方向。

## 七宗罪与选品方向

| 人性弱点 | 选品方向示例 |
|---------|------------|
| 懒惰 | 智能家居、懒人用品、自动化工具 |
| 贪婪 | 优惠券、折扣商品、理财课程 |
| 傲慢 | 奢侈品、高端定制、炫耀性消费 |
| 嫉妒 | 社交攀比类产品、限量版商品 |
| 暴食 | 美食、零食、餐饮相关 |
| 色欲 | 美妆、健身、约会相关 |
| 暴怒 | 解压玩具、发泄类产品 |

## 在选品中的应用

- 提供了一种洞察用户深层心理需求的选品视角
- 能发现高潜力品类，尤其是情感驱动型产品
- 与数据驱动决策结合，验证选品想法是否真的有市场

## 相关概念

- 利他思维：七宗罪选品的互补视角，从“解决问题”出发
- 人群与场景分析：从人群和场景维度细分需求
- 多平台交叉验证：验证七宗罪选品结果的方法
