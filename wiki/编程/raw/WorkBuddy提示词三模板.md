# WorkBuddy提示词三模板

## 核心公式

优质提示词 = 角色 + 任务 + 背景 + 具体要求

## 模板一: 任务型提示词

**结构**:
```
【角色】你是一位[身份/专业领域]的专家
【任务】帮我[具体任务]
【背景】背景情况为[相关情况]
【要求】
- 格式:[具体格式要求]
- 受众:[目标受众]
- 风格:[具体风格]
- 长度:[大致字数]
```

**示例**:
```
你是一位拥有10年经验的HR专家。帮我写一封回绝候选人的邮件。

背景是该候选人历经3轮面试，最终因薪资预期差距较大而无法录用。

要求如下:
- 格式:正式邮件
- 语气:委婉且明确，避免歧义
- 字数:150字以内
- 需表达对候选人的肯定与感谢
```

## 模板二: 分析型提示词

**结构**:
```
【数据/材料】[附上相关数据或说明情况]
【分析角度】请从[具体维度]展开分析
【输出形式】以[表格/要点/段落]形式呈现
【结论要求】需给出[可操作的建议/优先级排序/具体数字]
```

**示例**:
```
以下是我们上个月的用户反馈数据(表格已上传)。

请从以下3个角度进行分析:
1. 最常见的投诉类型
2. 各类型的严重程度
3. 哪些问题最易解决且影响最大

以表格形式呈现分析结果，并在最后给出3条优先处理建议。
```

## 模板三: 迭代型提示词

**追问句式对照表**:

| 情况 | 追问方式 |
|------|----------|
| 内容冗长 | "帮我将内容精简至500字以内，确保核心观点得以保留" |
| 表述过于官方生硬 | "将表述修改得更加口语化，仿若与朋友交谈一般" |
| 细节缺失 | "对第3点进行详细展开，补充具体的操作步骤" |
| 方向偏离 | "重新聚焦于[XXX]这一角度" |
| 期望变体 | "为我提供3个不同风格的版本" |

## 实战: 三步撰写商务邮件

**第一步**: 提供基本信息
```
帮我撰写一封邮件，告知客户项目延期2周，原因是第三方接口对接出现问题，我方正在积极处理，预计3月30日前完成。
```

**第二步**: 优化语气
```
将语气调整得更为诚恳，充分体现我方对此事的高度重视，同时增添一句"如有任何疑问欢迎随时联系"。
```

**第三步**: 调整格式
```
添加邮件主题，并将格式调整为标准商务邮件格式。
```

## 练习题

下次给AI任务时，先思考这4个问题:
1. 我期望达成何种结果?
2. 该结果的受众是谁?
3. 有哪些格式或风格方面的要求?
4. 有哪些内容是不能出现的?
