# 图形语言

## 定义

图形语言是利用基础图形（圆、方、三角）和线条的情感属性与象征意义来传达信息和情绪的理论。它是“物发展成图”的过程，具备直观性、生动性、象征性、艺术性，可传递潜在含义。

## 与正负形的关系

正负形的解析力与图形语言相辅相成，对图形形状的感知越强，画面简化理解能力越好。黑白正负形是图形语言的基础，图形语言是正负形的进阶应用。

## 基础图形的情感属性

| 图形类型 | 情感/象征意义 |
|---------|--------------|
| **圆形** | 温柔、柔软；微观视角下可凸显场景的庞大感 |
| **方形** | 体现工业化时代特征，让建筑更稳定、现代 |
| **三角形（正）** | 稳定、庄严、神圣 |
| **三角形（倒）** | 攻击性、威胁感、危险、紧张 |
| **三角形（一般）** | 动态、攻击性 |

## 线条的情感表达

| 线条类型 | 情感/象征意义 |
|---------|--------------|
| **曲线** | 柔和、流动、流畅 |
| **直线** | 稳定、直接、刚硬 |
| **横线** | 平静、开阔 |
| **折线** | 紧张、冲突 |
| **对角线** | 动感、冲突 |
| **对抗对角线** | 冲突、张力 |
| **放射线** | 爆发、扩张、聚焦、能量 |
| **弧线** | 安全感 |

## 应用原则

- **情感匹配**：选择与画面主题情感相匹配的图形和线条。
- **组合运用**：可组合多种图形语言创造复杂情感表达。
- **文化差异**：注意不同文化背景下图形象征意义的差异。

## 进阶运用

### 基础图形组合
- 基础图形进阶组合（如框中框），随信息量增加，画面更耐看、故事丰富度更高

### 场景应用
- 弧线条背景 = 安全感
- 倒三角场景 = 危险感

### 特殊作用
- 衔接断裂的视觉元素，拓展联想空间
- 可串联人物、建筑、物件形成具象形态并融合

## 关联概念

- 视觉平衡: 图形语言对于平衡的视觉元素至关重要
- 黑白正负形: 与图形语言相辅相成
- 图形概括解析力: 图形语言的感知基础
- 视觉引导: 图形语言可用于引导视线
- 构图创作工作流: 图形语言在创作流程中的应用
