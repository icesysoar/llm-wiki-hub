从包装好的新郎身上拆下新郎的组件。
### Parameters
Grooms can be packaged using the [Groom Pack SOP](https://www.sidefx.com/docs/houdini/nodes/sop/packgroom.html "Packs the components of a groom into a set of named Packed Primitives for the purpose of writing it to disk.").

The package can contain both the static and animated guide curves and skin.
