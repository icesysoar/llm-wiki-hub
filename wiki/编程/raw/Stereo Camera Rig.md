 t## 使用立体摄像机装备
1.  在[网络编辑器](https://www.sidefx.com/docs/houdini/ref/panes/network.html)中用鼠标按 ⇥ Tab。
2.  键入**“立体声相机”**，然后从菜单中选择它。
3.  从视口右上角的摄像机菜单中选择新创建的摄像机节点。
    注意
    您将看到四个条目，一个用于右侧摄像机，一个用于左侧摄像机，一个用于中心摄像机，一个用于整个立体装备。从该菜单中选择立体装备节点将在视口中启动立体查看。
4.  通过单击右侧工具栏上的“锁定摄像机”![](https://www.sidefx.com/docs/houdini/icons/VIEW/display_lock_camera.svg)按钮锁定视图和**摄像机**。这允许您在保持立体构图的同时操纵视点和方向。
    注意
    您将需要一副标准的红青色滤镜眼镜，也称为立体眼镜，以感知立体深度。
提示
您可以通过在视口显示选项中选择相应的复选框来隐藏遮挡视图的视口 gnomon。

### 改造子摄像头
有一个调用的备用参数，它允许您指定在视口锁定时应更改其转换的节点。这对于同步 HDA 中的子摄像机（和子灯）非常有用。`viewxformpath`
通常，子相机无法更新，因为它们的参数被锁定。如果子摄像机具有指定顶级节点的参数，则当视口锁定并浏览子摄像机并平移或旋转视图时，将修改顶级节点的变换参数以保持视口中的视图。顶级 HDA 应指定一个具有代表性的摄像机，以便 Houdini 将其视为摄像机本身。`viewxformpath`
例如，立体摄像机装备有四个子摄像机，每个子摄像机都有指定顶级节点的参数。您可以查看这些子摄像机中的任何一个，并调整整个装备的变换，以便视口的视图与子摄像机的视图（如左侧摄像机）相对应。`viewxformpath`
有关添加备用参数的详细信息，请参阅[编辑参数接口帮助](https://www.sidefx.com/docs/houdini/ref/windows/edit_parameter_interface.html "Creates, imports, or edits parameters on a node.")。
## 高级渲染
Houdini、mantra 和 MPlay 为立体声装备和图像提供了基本支持，这些装备和图像面向简单的第一步。例如，使用默认设置从 mantra 渲染到 MPlay 很容易，但显示次映像平面（如深度）可能更难。类似地，虽然将立体摄像机视图渲染为一对图像文件可能很简单，但可能不适合更高级的渲染。
在更高级的情况下，创建自定义渲染节点数字输出。它应该包含两个咒语节点，一个明确用于左侧子摄像头，另一个用于立体声主摄像头装备的右侧子摄像头。这样可以更轻松地分别调整左右通道的各种设置、输出平面和输出文件。
您还可以构建自己的 ROP HDA，通过在预渲染和渲染后脚本中设置各种变量和摄像机参数值，可以进一步自定义渲染通道。

## 变换
转换顺序
左侧菜单选择应用转换的顺序（例如，缩放、旋转、平移）。这可以改变物体的位置和方向，就像走一个方块并转向东方会把你带到一个不同的地方，而不是向东转，然后去一个方块。
右侧菜单选择围绕 X、Y 和 Z 轴旋转的顺序。某些顺序可以使字符联合转换更易于使用，具体取决于字符。
翻译

旋转

支点
对象的本地原点。另请参阅[设置枢轴点](https://www.sidefx.com/docs/houdini/basics/objects.html) 。
修改转换前
此菜单包含用于操作[转换前](https://www.sidefx.com/docs/houdini/basics/objects.html#pretransform)值的选项。预转换是在常规转换参数之前应用的内部转换。这允许您更改以下平移、旋转和缩放参数值的参考系，而无需更改整体变换。
清理转换
这会将平移、旋转、缩放参数还原为其默认值，同时保持相同的总体变换。
干净的翻译
这会将 translate 参数设置为 （0， 0， 0），同时保持相同的总体转换。
清洁旋转
这会将旋转参数设置为 （0， 0， 0），同时保持相同的总体变换。
清洁鳞片
这会将 scale 参数设置为 （1， 1， 1），同时保持相同的总体变换。
提取预转换
这将通过设置平移、旋转和缩放参数来删除预转换，以保持相同的整体变换。请注意，如果预变换中存在剪切力，则无法完全移除。
重置转换前
这将完全删除预转换，而无需更改任何参数。如果平移、旋转和缩放参数中存在任何非默认值，这将更改对象的整体变换。
育儿时保持姿势
重新设定对象父级时，通过更改对象的变换参数来保持其当前世界位置。
儿童赔偿
当对象正在转换时，通过更改其转换参数来维护其子对象的当前世界转换。
启用约束
在对象上启用**约束网络**。
约束
通往 CHOP **约束网络的**路径。另请参阅[创建约束](https://www.sidefx.com/docs/houdini/character/constraints.html)。
提示
您可以使用约束下拉按钮激活约束功能区工具之一。如果这样做，则第一个选取会话将由参数面板中选定的节点自动填充。
注意
对象节点上的 Lookat 和 Follow Path 参数已弃用，取而代之的是[看](https://www.sidefx.com/docs/houdini/shelf/constraintlookat.html "Makes an object point at another object.")和[跟踪路径](https://www.sidefx.com/docs/houdini/shelf/constraintpath.html "Animates an object along a curve.")约束。这些参数目前仅处于隐藏状态，如果您确实编辑了节点的参数界面，则可以设置其可见性。
## 立体声
零视差设置
控制从相机测量到的 ZPS 平面的距离。
ZPS是空间中的一组点，其左投影和右投影在显示图像中的同一点重叠。ZPS 平面与查看屏幕重合。照相机和 ZPS 平面之间的对象在查看屏幕前向查看者显示，ZPS 平面后面的对象在查看屏幕后面向查看者显示。
ZPS at Infinity
如果此复选框处于打开状态，则 ZPS 值将被视为无穷大。无穷远处的点将显示在屏幕上，所有其他点将出现在查看器和屏幕之间。这相当于使左右相机的光轴平行。
轴间距离
控制左右摄像机之间的分离距离，并直接可视化为视口中摄像机道具的一部分。增加此参数会将左相机和右相机都推离中心。
轴间距离是左右摄像机之间的距离。较大的值会产生更明显的立体效果，增强深度感，而较小的值会降低深度感。值为零将生成非立体影像。
左/右轴间调整
允许您微调左右相机镜头。这些参数会影响立体摄像机的整体轴间距离。
显示轴间控制
在相机镜头附近显示箭头。选择和移动这些对象会增加或减少立体摄像机的轴间距离。但是，如果您通过相机查看，则不会看到轴间控件。要查看和移动视口中的控件，![](https://www.sidefx.com/docs/houdini/icons/VIEW/display_lock_camera.svg)请解锁摄像机并切换到对象级别。控件的行为类似于[空对象](https://www.sidefx.com/docs/houdini/nodes/obj/null.html "Serves as a place-holder in the scene, usually for parenting. this object
does not render.").
![](https://www.sidefx.com/docs/houdini/images/shelf/stereocaminteraxial.jpg)
注意
要在照相机中查看时修改轴间距离，请将**“轴间距离”**参数拖动到视口中，然后使用“参差”。要移除滑块，只需单击 RMB 并关闭**显示**复选框。
启用脚趾插入
打开此复选框会将相机进入“脚趾进入”模式，允许左/右子相机的额外旋转。在此模式下，无法可视化 ZPS 平面，因为它不再是平面。它变成一个曲面。
注意
打开此功能后，应通过打开 ZPS **at Infinity 参数将 ZPS 设置为无穷大**。这将产生一个标准的脚趾入式立体摄像机装备，旋转由左/右旋转参数控制。
左/右旋转
确定子照相机的水平旋转。
左/右枢轴
确定相机围绕其旋转的枢轴点。
显示透视控件
在视口中显示相机附近的脚趾入式操纵器。您可以选择箭头来定位枢轴，也可以选择旋转器来调整每个摄像机的旋转角度。
显示 ZPS 标记和屏幕环绕
在查看立体图像时显示与物理屏幕对应的帧。
屏幕环绕是查看屏幕的左边缘、右边缘、顶部边缘和下边缘。此可视化有助于将场景中的对象相对于摄像机和屏幕环绕位置。摄像机和屏幕环绕可视化之间的对象将显示为从屏幕中弹出，朝向查看器。
![](https://www.sidefx.com/docs/houdini/images/shelf/stereocamzps.jpg)
注意
可以在视口中选择和移动屏幕框架以调整ZPS距离。此外，还会显示 ZPS 箭头标记，以便在通过立体摄像机沿 z 轴选择并拖动立体摄像机进行查看时，可以使用该标记进行调整。
显示视锥体
显示多个视锥体。
中心
显示中央摄像头的视锥体。
左
显示左侧摄像头的视锥体。
右
显示正确相机的视锥体。
左和右
显示叠加的左右视锥体的视锥体。
左右交集
定义在左侧和右侧图像中都可以看到其点的空间区域。此区域中的对象将保持立体外观，对于靠近屏幕环绕的左右边缘的对象，立体外观有分解的趋势。例如，在此视锥体之外。
注意
这些视锥体由近剪裁平面和远剪平面分隔。这些是装备上的独立参数，但通常习惯上将其值与屏幕环绕声相关联。例如，在远离 ZPS 平面的宽度的 1.5% 处。这可以在立体摄像机装备中实现，在近场和远部削波平面参数中使用适当的通道参考和乘法器。
半透明视锥体
视锥体显示为半透明多边形，而不是线框轮廓。这对于估计哪些对象位于视锥体内部或外部以及哪些对象部分越过边界非常方便。
提示
当半透明可视化处于打开状态时，视锥面将使在视口中选择所包含的对象变得更加困难。暂时将查看器切换到线框（热键）进行选择，然后再次按下以返回着色模式，其中再次显示半透明笼。`w``w`

允许调整视锥体透明度。
