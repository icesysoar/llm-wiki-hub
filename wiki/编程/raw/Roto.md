如果您只进行转描，Roto 节点是最佳选择 - 它允许您创建和编辑贝塞尔和 B 样条曲线形状。

查看器左侧的工具栏包括点选择和操作以及形状创建工具。单击并按住或右键单击工具栏按钮以打开子菜单以选择其任何可用的工具类型。与当前工具相关的选项显示在查看器顶部的工具栏中。单击工具栏项可循环浏览该类工具的可用选项。

作为一般工作流程指南：

|   |   |   |
|---|---|---|
||1.|从左侧查看器工具栏中选择您的工具。|

|   |   |   |
|---|---|---|
||2.|使用查看器上方的旋转工具设置来调整工具的属性。|

|   |   |   |
|---|---|---|
||3.|绘制一个或多个形状：|

• 在查看器中单击以放置点。您可以在单击时拖动以拉出贝塞尔手柄或调整 B 样条线张力。

• **按 Ctrl**/**Cmd**+拖动以自由绘制形状。

• 若要关闭形状，请单击第一个点或按 **Return 键**。若要使形状保持打开状态，请按 **Esc**。

• **按 Ctrl**/**Cmd**+**Alt**+单击可向现有形状添加点。

• 要增加点的平滑度，请选择该点并按下 **Z**。

• 要达到某个点，请选择该点并按 **Shift**+**Z**。

• 要删除点，请选择该点，然后按 **Delete** 键。

• 贝塞尔：**按住**切线手柄+拖动，将相反的手柄捕捉到相同的长度。在切线手柄上**按 Ctrl**/**Cmd**+拖动以独立于其相反的手柄移动它。

• B 样条曲线：在点上**按 Ctrl**/**Cmd**+**Alt**+拖动以调整其张力。

|   |   |   |
|---|---|---|
||4.|使用“选择”工具或控制面板中的形状列表**选择**形状。|

|   |   |   |
|---|---|---|
||5.|使用控制面板调整或微调形状。|

您也可以通过在节点图上按 **O** 来创建此节点。

另请参阅[RotoPaint](https://learn.foundry.com/nuke/14.0/content/reference_guide/draw_nodes/rotopaint.html)。
