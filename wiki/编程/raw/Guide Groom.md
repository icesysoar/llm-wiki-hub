# Object nodes

### Guide Groom^Object
#### ![](https://www.sidefx.com/docs/houdini/icons/OBJ/guidegroom.svg)导游毛发
用动画皮肤和可选的引导曲线对几何体进行变形
## Parameters
此节点是为任何类型的毛发创建参考线的工具。
#### Grooming radial menu 毛发菜单
使用引导修饰 SOP 时，请确保从顶部菜单栏切换到“毛发梳理毛发径向”菜单。此菜单允许您在视口中快速切换工具选项，这是使用此节点时推荐的工作流。
![](https://www.sidefx.com/docs/houdini/images/fur/guidegroom_radialmenu.png)
切换到毛发修饰毛发径向后，可以通过按 C 将其打开。这将打开一个菜单，其中包含向导整理 SOP 的所有毛发“工具毛发”选项，并反映节点上毛发“工具毛发”下拉参数中可用的选项。这是在此节点上的选项之间切换的快速方法。
![](https://www.sidefx.com/docs/houdini/images/fur/guidegroom_radialmenu_top.png)
![](https://www.sidefx.com/docs/houdini/images/fur/guidegroom_radialmenu_submenu.png)
例如，如果您将鼠标悬停在毛发“创建和移动”毛发上，您将看到可用于创建和移动头发的4个选项。您可以选择一个，也可以通过将鼠标悬停在双箭头上来导航回上一个级别。
每个毛发工具毛发都有一个该模式独有的毛发“工具选项”毛发菜单。例如，毛发“绘制”毛发模式下可用的工具选项与“毛发植物毛发”模式下可用的工具选项不同。
#### Tool工具
本节通过上述径向菜单记录指南 Groom 视口状态中可用的工具。
##### 创建和移动
**Draw 绘画**

绘制单独的头发曲线。
单击并拖动角色的皮肤，然后从中绘制以创建头发曲线。
可以使用各种选项来修改绘图行为。您可以通过启用在皮肤上绘制整个头发来毛发绘制角色皮肤上的整个头发毛发。
通过将“毛发曲线类型”毛发更改为 来绘制分型线。
创建的曲线段数由毛发“线段模式”毛发参数控制。将此设置为创建具有预定义段数的头发。将其设置为以便为较长的曲线创建更多线段。`Fixed``Adaptive`

**Plant 植发**

单击角色皮肤以在此时创建头发。
要创建多个毛发，请切换到毛发散射模式毛发并设置毛发半径毛发和毛发密度毛发参数。断续器删除画笔下的曲线。
要匹配周围毛发的形状，请启用毛发插值参考线毛发。禁用此功能（或当没有毛发时），新毛发将直接从表面伸出。然后，长度由毛发“默认长度”参数控制毛发。
毛发相对于皮肤插值毛发将插值周围的毛发，但旋转创建的头发以匹配单击点的皮肤曲率。

**Move 移动**
在角色外观周围移动点。
要随皮肤的曲率旋转点，请启用毛发“与皮肤一起旋转”毛发
**Relax 放松**
均匀头发之间的间距。您可以使用毛发密度毛发参数控制空间量。
**Delete 删除**
删除刷子下的头发。
**Cull 剪切**
删除头发，直到密度与毛发“密度”毛发参数匹配。
**Sculpt 造型**
雕刻毛发造型，通过单击和拖动来雕刻曲线。
**Smooth 光滑**
平滑曲线的形状，删除任何高频细节。
毛发平滑度毛发参数越高，平滑的细节就越多。
**Clump 丛**
将光标下的任何曲线聚集在一起。您可以一次对整个曲线执行此操作，也可以使用毛发“每点”毛发以更可控的方式执行此操作。
断续器分隔曲线。
**Sculpt with Physics 用物理雕刻**
使用牛皮纸物理进行模拟时刷头发。
启用毛发实时模拟毛发以始终运行模拟，即使在不主动刷牙时也是如此。
使用毛发稳定模式毛发在重力作用下掉落头发。
使用毛发阻尼模式毛发获得物理模拟的效果，头发无重力漂浮。
###### Blur 模糊
混合（平均）刷子下头发的形状。
##### Brush & Edit 刷子和编辑
###### Deintersect 去交叉
尝试修复皮肤交叉点，其中部分头发潜入角色的皮肤下。
###### Transform Handle 转换句柄
使用此工具可以使用变换手柄移动曲线或单个点。
毛发“软转换”毛发会根据“软转换”模式对整个曲线或其部分毛发进行软转换毛发。
⇧ 按住手柄并拖动以克隆曲线。也可以仿制端点以延伸曲线。
```
提示
执行此操作后，可以使用 Shift+D 沿曲线均匀地重新分配点。或者使用 Shift+R 重新采样为其他段计数。
```
###### Brush 刷
梳理头发，从根部旋转。
还可以通过增加“折弯”参数来毛发折弯毛发毛发。折弯的形状由毛发折弯衰减控制毛发。
###### Adjust Length 调整长度
在毛发加/减模式下毛发，LMB增加长度，MMB减小。
毛发“设置模式”毛发会调整长度，直到它与毛发“长度”毛发参数匹配。
使用毛发比例法毛发，头发形状可以均匀缩放。
使用毛发切割/延伸方法毛发，头发在尖端延伸或修剪。
###### Lift 电梯
更改毛发相对于皮肤平面的方向。
在毛发加/减模式下毛发，LMB 升高，MMB 降低。
在毛发“设置模式”中毛发，将旋转头发，直到角度与设置毛发的角度毛发参数匹配。
###### Straighten 伸直
将整个发型拉直成一条直线，保持原来的长度。
##### Group & Mask
###### Paint Group Tool 画图组工具
默认情况下，这会将当前设置毛发的活动名称毛发绘制到曲线上，但您也可以更改毛发“组”毛发标题下的参数，以改为将拉丝曲线添加到组中。
###### Paint Mask Tool 画图遮罩工具
绘制蒙版属性。其他工具使用此功能将其效果限制为绘制区域。通过启用“绘画点”，可以按点毛发绘制蒙版毛发。
断续器添加到掩码中，MMB 将删除。
有关更多信息，请参阅使用[指南新郎创建和样式设计指南头发](https://www.sidefx.com/docs/houdini/fur/groom.html)页面。
#### 参数
清楚
清除所有编辑内容，如果未连接输入，则会重置为未修改的输入或根本没有几何图形。
群
当前要修饰的选定元素。
组类型
当前所选内容的元素类型。
使用面膜
减少基于彩绘蒙版的画笔和工具的效果。使用“画图蒙版”工具修改此蒙版。
您还可以在“[修饰径向菜单”](https://www.sidefx.com/docs/houdini/nodes/sop/guidegroom.html#groomradial)中找到与蒙版相关的工具
工具
当前选定的工具。在工具之间切换的最方便方法是使用“[修饰径向菜单”](https://www.sidefx.com/docs/houdini/nodes/sop/guidegroom.html#groomradial)。
射线偏差
角色皮肤周围碰撞层的厚度。引导 Groom SOP 可防止曲线在编辑时穿过此外层。
理想值是新郎中最短段长度的 1/10 或 1/100。使其更大将使曲线点与皮肤保持很远的距离。使它太小会使曲线更容易最终进入皮肤内部。
将所选内容编辑为团块
刷洗所选内容将修改其整体，就好像所有选定的曲线都聚集在一起一样。这样可以更轻松地在雕刻时保留现有团块的体积。
与皮肤碰撞
防止引导线穿过角色的皮肤。在某些情况下，将其关闭可能很有用。例如，当指南已经卡在皮肤内并且您想要将它们移回时。
#### 画笔选项
表面刷
在角色的表面上刷子。关闭此复选框后，画笔位于屏幕空间中。大多数工具都以任何一种方式工作，但对于某些工具（如毛发Plant毛发），这始终是启用的，因为只有在皮肤表面上植入导轨才有意义。
尊重分界线
打开此复选框后，画笔将仅影响分型线光标一侧的参考线。这仅在打开 毛发Surface 画笔毛发时才有效，因为画笔的投影外观位置用于确定其位于哪一侧。
屏幕半径
关闭“表面画笔”时的毛发画笔毛发半径（以像素为单位）。
对象半径
以 Houdini 为单位的画笔半径（当 毛发Surface 画笔毛发处于打开状态时）。
强度
刷子效果的强度。
柔软
刷子形状的柔软度。
间距
当此值不为零时，无论光标移动速度如何，画笔都将以固定的像素间隔溅射。这仅在关闭毛发“表面画笔”毛发时才有效。
每点
按点而不是按曲线应用操作。
保持长度
刷牙时保留曲线长度的量。小于 1 的值允许您通过沿曲线刷线来修改曲线长度。
弯曲
值大于 0 会导致曲线在刷牙时弯曲得更多，而不仅仅是从根旋转。
弯曲脱落
值越高会导致曲线在尖端处弯曲得更多，值越低会导致它们在根部更容易弯曲。
与皮肤一起旋转
在移动曲线时随皮肤曲率一起旋转曲线。
约束长度
在雕刻时约束曲线段的长度。
锁定根目录
在雕刻时将根锁定到位。
平滑
模式
加/减
在继续刷牙时不断提升皮肤的曲线。
设置
提升至设定量。
绘画点
绘制单个点的蒙版值，而不是绘制整个曲线。
角度
提升工具的目标角度。
模式
加/减
连续向 LMB 添加或从 MMB 中减去曲线长度。
设置
刷牙时调整为预定的绝对长度。
价值
要调整依据的值。
长度
要调整的长度。
方法
切割/延伸
刀尖处的切口或范围，与刀尖方向相匹配。
规模
缩放整个曲线，保持其形状。
模式
单
在初始单击位置放置一条曲线。
散射
在半径内散射曲线
密度
每平方单位要散射的曲线数。
默认长度
种植曲线的长度。当“毛发插值参考线”毛发处于打开状态时，将忽略此值，因为曲线将与附近参考线的形状和长度匹配。
相对于皮肤的模糊
保留曲线相对于皮肤的方向。
区段计数
具有此段数的工厂曲线。
插值参考线
插值附近参考线曲线的形状。
相对于皮肤插值
插入参考线时，还要保持形状相对于角色皮肤的方向。
曲线类型
指导
绘制常规参考线。
分型线
在角色的皮肤上画分界线。
在皮肤上绘画
在角色的皮肤上绘制参考线。关闭此选项后，绘制的第一个点将位于外观上，但后续点将在屏幕平面中绘制。
分段模式
固定
绘制具有固定段数的参考线。
适应的
在绘制较长的曲线时创建更多线段，尝试匹配下面的毛发“线段长度”毛发集。
区段计数
“分段毛发模式”设置为“固定”时的段毛发数。
段长度
模拟模式
阻尼
弯曲和拉伸约束是计算的，但头发在重力作用下不会掉落。
解决
完整的物理模拟，包括在重力下坠落。
实时模拟
即使不主动刷牙也能进行模拟
时间刻度
应用于模拟时间步长的总体比例。较大的值会减慢模拟速度。
重力
重力矢量。
约束根方向
约束第一条曲线段的方向。
强度
物理刷的强度。
弯曲刚度
控制模拟头发的抗弯曲性。
拉伸刚度
控制模拟头发的拉伸阻力。
设置休息状态
将其余状态设置为当前模拟状态。完成此操作后，您可以跳回其他工具并返回毛发“使用物理进行雕刻”毛发，头发不会进一步掉落或沉降。
清除休息状态
清除任何设置的休息状态。
#### 实用程序选项
分段模式
固定
使用每条曲线的固定段数重新取样。
适应的
重新采样以使给定的线段长度匹配，并根据需要放置任意数量的曲线段。
添加点
在两个现有点之间添加新点。
移除点
删除除根和尖端之外的所有点，并生成一条直线。
区段计数
所需段的数量。
段长度
所需的段长度。
角度
以度为单位的总角度。
镜子
启用实时镜像。
镜像组
要镜像的基元组。
起源
用于镜像的原点。
方向
镜像平面的方向矢量。
预览
预览实用程序的结果。
应用
将当前参数值的结果烘焙到 groom 中。
