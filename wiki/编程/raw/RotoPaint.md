RotoPaint 是一个基于矢量的节点，可帮助完成转描、钻机移除、垃圾消光和除尘等任务。您可以使用单个和图层组属性绘制贝塞尔和 B 样条形状，包括每个点和全局羽化、运动模糊、混合模式以及单个或分层 2D 变换。

RotoPaint 节点为您提供了比 [Roto](https://learn.foundry.com/nuke/14.0/content/reference_guide/draw_nodes/roto.html) 更广泛的工具，尽管许多控件在两个节点之间共享。与 Roto 节点一样，应使用查看器工具创建形状和绘制笔触，然后使用控制面板对其进行编辑。

查看器左侧的工具栏具有与 Roto 节点相同的点选择和操作以及形状创建工具。此外，RotoPaint 节点还具有画笔、克隆/显示、模糊和减淡/加深工具。单击并按住或右键单击工具栏按钮以打开子菜单以选择其任何可用的工具类型。与当前工具相关的选项显示在查看器顶部的工具栏中。单击工具栏项可循环浏览该类工具的可用选项。

作为一般工作流程指南：

|   |   |   |
|---|---|---|
||1.|从左侧查看器工具栏中选择您的工具。|

|   |   |   |
|---|---|---|
||2.|使用查看器上方的 RotoPaint 工具设置来调整工具的属性。|

|   |   |   |
|---|---|---|
||3.|绘画时，您可以：|

• **在**查看器上移动+拖动以更改画笔大小。

• 克隆工具：**按 Ctrl**/**Cmd**+单击并拖动以设置克隆偏移量。要重置克隆偏移量，请**按 Ctrl**/**Cmd**+**Shift**+单击并拖动。

|   |   |   |
|---|---|---|
||4.|绘制形状时，您可以：|

• 在查看器中单击以放置点。您可以在单击时拖动以拉出贝塞尔手柄或调整 B 样条线张力。

• **按 Ctrl**/**Cmd**+拖动以自由绘制形状。

• 单击第一个点或按 **Return** 键关闭形状。若要使形状保持打开状态，请按 **Esc**。

• **按 Ctrl**/**Cmd**+**Alt**+单击可向现有形状添加点。

• 选择一个点并按 **Z** 键以增加该点的平滑度。

• 选择该点，然后按 **Shift**+**Z** 键使该点达到尖点。

• 选择点，然后按 **Delete** 删除点。

• 贝塞尔：**按住**切线手柄+拖动，将相反的手柄捕捉到相同的长度。在切线手柄上**按 Ctrl**/**Cmd**+拖动以独立于其相反的手柄移动它。

• B 样条曲线：在点上**按 Ctrl**/**Cmd**+**Alt**+拖动以调整其张力。

|   |   |   |
|---|---|---|
||5.|使用控制面板中的“选择工具”或“形状/描边”列表**选择**形状或描边。|

|   |   |   |
|---|---|---|
||6.|使用控制面板调整或微调形状或笔触。|

您还可以通过在节点图上按 **P** 来创建此节点。

另请参阅 [Roto](https://learn.foundry.com/nuke/14.0/content/reference_guide/draw_nodes/roto.html)、[Project3D](https://learn.foundry.com/nuke/14.0/content/reference_guide/3d_nodes/project3d.html)、[F_RigRemoval](https://learn.foundry.com/nuke/14.0/content/reference_guide/furnacecore_nodes/f_rigremoval.html) 和 [F_WireRemoval](https://learn.foundry.com/nuke/14.0/content/reference_guide/furnacecore_nodes/f_wireremoval.html)。

|颜色|颜色|1|设置旋转形状或绘画描边的颜色。仅当“**形状**”或**“描边**”选项卡上的**源**设置为**颜色**时，此控件才起作用。|
|不透明度|不透明度|1|设置形状/描边列表中新形状或现有形状或描边的不透明度。1 等于完全不透明，0 等于透明。|
|源|paint_source|颜色|设置所选形状/描边的源颜色：<br><br>• 颜色 - **在色**域中指定的**颜色**。<br><br>• **前景** - 从 **BG** 输入中提取像素，包括在其上绘制的任何形状和笔触。此输入主要用于**“克隆**”选项卡控件。使用它可能会导致渲染速度变慢。<br><br>• **背景** - 从 **BG** 输入中提取像素，不包括在其上绘制的任何形状和笔触。<br><br>• **背景 1 到 3** - 从 BG1、**BG2 和 BG3** 输入中提取像素。|
|混合模式|blending_mode|多|设置当前形状 （A） 中的颜色如何与基础图像和形状 （B） 合并：<br><br>• **颜色加深**（使 B 朝 A 变暗） - 通过增加对比度使 B 变暗以反映 A。图像的任何部分都不会变亮。<br><br>• **颜色减淡**（使 B 朝 A 方向变亮） - 通过降低对比度使 B 变亮以反映 A。图像的任何部分都不会变暗。<br><br>差异（abs**（**A-B）） - 从A中减去B，反之亦然，具体取决于哪个更亮。与白色混合反转A，而与黑色混合不会产生任何变化。相似的颜色将返回黑色像素。<br><br>• **排除** （A+B-2AB） - 创建类似于**差分**模式但对比度较低的结果。与**差异**一样，与白色混合反转A.与黑色混合不会产生任何变化。<br><br>• **从** （B-A） - 从 B 中减去 A。<br><br>•**硬光**（如果A<.5乘以，如果A>.5，则屏幕） - 使高光变亮并使阴影变暗。如果 B 的灰度低于 50%，则结果会变亮，就像经过筛选一样。如果 B 的灰度比 50% 深，则结果会变暗，就像相乘一样。<br><br>• **max** （max（A，B）） - 选择两种颜色中较浅的颜色作为结果颜色。仅替换比 B 暗的区域，而比 B 亮的区域不会更改。<br><br>• **min** （min（A，B）） - 选择两种颜色中较暗的颜色作为结果颜色。任何比 B 轻的零件都将被替换。图像中比 B 暗的任何部分都不会更改。|
|混合模式（续）|||• 减号 （A-B） - 从 A 中**减**去 B。<br><br>• **乘法**（AB，A 如果 A<0 和 B<0） - 将 A 乘以 B。结果总是更暗。与黑色混合会产生黑色，与白色混合将返回颜色不变。<br><br>• over（A **over** B） - 两张图像的颜色不会以任何方式相互作用，Nuke将显示A中颜色的全部值。<br><br>•**叠加**（如果B<.5则乘以，如果B>.5则屏幕） - 根据A，乘以或屏蔽颜色。B 使 A 变亮，同时保留高光和阴影。<br><br>• **加号** （A+B） - 两种颜色的总和。增加亮度以使 A 变亮并反射 B.Plus 类似于**屏幕**混合模式，但会产生更极端的结果。<br><br>•**屏幕**（如果A和B在0-1之间，则为A + B-AB，如果A>B则为B） - 这是一个柔和**的加号**，使一切更亮，但逐渐减少白色。浅色比深色具有更多的效果。结果始终是较浅的颜色。与黑色混合会使像素保持不变，与白色混合始终返回白色。结果类似于将多张幻灯片相互叠加。<br><br>• **柔光** - 根据 A 的不同，使颜色变暗或变亮。不如**硬光**混合模式极端。|
