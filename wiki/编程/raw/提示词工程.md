# 提示词工程

提示词工程（Prompt Engineering）是设计和优化输入给大语言模型的文本，以获得更好输出的技术。

## 基础原则

1. **清晰明确**：避免模糊指令
2. **提供上下文**：给出足够的背景信息
3. **分步思考**：引导模型逐步推理（Chain-of-Thought）
4. **示例驱动**：提供输入输出示例（Few-shot）

## 高级技巧

### Chain-of-Thought（思维链）

让模型展示推理过程，显著提高复杂推理任务的准确率。

**示例：**
```
请解决这个问题，并展示你的思考步骤：
问题：...
```

### Tree of Thoughts（思维树）

探索多条推理路径，评估每个步骤，选择最优解。

### 角色扮演

让模型扮演特定角色，获得更专业的输出。

**示例：**
```
你是一位资深的数据科学家。请分析以下数据...
```

### 自我一致性

生成多个答案后，选择最一致的结果。

## 实践建议

1. 从简单提示词开始，逐步迭代
2. 记录有效的提示词模式（提示词模式库）
3. 测试边界情况
4. 结合业务场景定制
