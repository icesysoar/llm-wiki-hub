# Side Effects Software

Side Effects Software 是 Houdini 的开发商，总部位于加拿大。该公司专注于创建高级视觉效果工具，以开发高度程序化的三维计算机图形软件而闻名。其旗舰产品 Houdini 是一款节点化的三维计算机图形软件，广泛应用于电影、游戏和视觉特效行业。

## 核心产品

- **Houdini** — 节点化三维计算机图形软件
- **Houdini Engine** — 将 Houdini 技术集成到其他应用程序中的 SDK
