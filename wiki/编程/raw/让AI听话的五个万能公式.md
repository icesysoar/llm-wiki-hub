# 让AI听话的五个万能公式

## 核心观点

AI就像一个能力超强但没常识的实习生，你不交代背景、不给格式，它只能靠猜。猜错了别怪它，怪你没给指令。

## 公式一: 角色设定法

```
你是一位[经验年限]的[职业角色]，擅长[核心能力]。
请帮我[具体任务]，目标对象是[用户画像]，重点突出[核心卖点]。
```

**为什么有效**: 角色设定等于给AI装了"专业大脑"

## 公式二: 背景注入法

```
我的情况: [年龄/职业/现状/限制]
目标是: [量化目标+时间周期]
请帮我[任务]，注意避开[限制/禁忌]
```

**为什么有效**: 背景信息是AI的"导航起点"

## 公式三: 步骤拆解法

```
请分[N]步完成任务:
第1步[内容]，第2步[内容]...
每步单独输出，小标题区分。
```

**为什么有效**: AI一次输出长内容容易"飘"，拆成步骤逻辑更清晰

## 公式四: 示例引导法

```
请帮我[任务]，参考以下示例风格: "[示例]"
请模仿示例的[风格特征]来输出。
```

**为什么有效**: 示例比描述强100倍，立刻对齐期望

## 公式五: 约束框定法

```
请帮我[任务]。
要求: 格式[格式]，字数[范围]，语气[风格]，不要[排除项]
```

**为什么有效**: 四维卡死(格式/字数/语气/禁区)，AI就没空间发挥"废话特长"

## 终极组合: 五个公式叠满

```
你是一位[角色](角色设定法)。
我的情况是[背景](背景注入法)。
请分[N]步完成(步骤拆解法)，
参考以下示例风格: "[示例]"(示例引导法)。
要求: 格式[格式]，字数[范围]，语气[风格]，不要[排除项](约束框定法)。
```
