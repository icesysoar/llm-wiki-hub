# 负面价值三层次

负面价值三层次是提升故事深度的核心进阶概念，由“相反价值”、“矛盾价值”、“负面之负面”三个递进层次构成。故事深度取决于对负面价值的挖掘程度——仅达到矛盾价值的故事趋于平庸，必须达到“负面之负面”才能辉煌、崇高。

## 三个层次

### 第一层：相反价值
轻微负面，非完全对立。例如以“正义”为例，相反价值包括不公平、偏见、拖延。这一层次制造轻度冲突和张力。

### 第二层：矛盾价值
直接对立。例如以“正义”为例，矛盾价值是非正义、违法。这一层次制造直接对抗和戏剧冲突。

### 第三层：负面之负面
双重否定，人性黑暗的极限。例如以“正义”为例，负面之负面是专制（强权即真理）。这一层次触及人性最深的黑暗面，是区分平庸与辉煌故事的关键。

## 各价值类型的负面之负面

| 正面价值 | 负面之负面 |
|---------|-----------|
| 正义 | 专制 |
| 爱情 | 自厌 / 以爱为面具的恨 |
| 真理 | 对自己撒谎并相信 |
| 交流 | 失去自我交流 |
| 智慧 | 自以为聪明的愚蠢 |
| 成熟 | 貌似成熟的不成熟 |

## 应用建议

- **第一幕**：正面 → 相反价值
- **中间幕**：矛盾价值
- **最后一幕**：双重负面（悲剧）或深刻回归正面

## 核心理念

正能量因负能量的存在而耀眼。尊重故事中的每一点负能量，将其作为推动故事深度和人物成长的核心动力。
