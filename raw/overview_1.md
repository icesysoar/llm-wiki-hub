# 项目总览

本维基是一个个人成长知识库，旨在系统化地记录、整理和反思与个人发展相关的知识、方法和实践。当前维基的核心主题围绕“阅读方法”、“知识转化”、“创作方法”、“AI交互”、“副业赚钱”、“审美设计”和“3D建模”展开，特别是基于《拆书·极简笔记》所提出的三种目的导向的拆书方法论，基于《大纲》所提出的系统化小说创作方法论，基于《破防了！用这套提示词让AI写小说，读者都以为是大神作品》所提出的AI小说创作三步法，基于《【闲鱼7天班】MVP 3.0 小白入门教材》所提出的闲鱼副业操作指南，基于《1黑白正负形的图形概括解析力》所提出的构图美学理论，以及基于《3D新人做次世代角色作品》所提出的3D角色建模入门指南。

维基目前收录了多种核心页面：**RIA便签法**（一种将知识转化为行动的主动阅读方法）、**拆书稿写作**（一种为他人讲解书籍的内容产品形式）、**小说拆解框架**（一种分析小说写作技巧的系统化方法）、**一句话记忆法**（对三种方法的精炼总结），以及**小说创作方法论**（从零开始构建小说的完整流程）。这些方法共同构成了一个完整的“拆书”与“创作”体系，强调目的决定方法，并鼓励行动导向的知识应用。

近期，维基引入了新的知识领域：**AI交互方法论**。该领域以**词条**概念为核心，探讨如何通过定义词语的特定含义来精确控制AI的行为。词条作为一种元工具，允许用户建立自己的术语体系，消除AI对指令的歧义理解，实现更复杂、更定制化的交互功能。这一新方向为维基提供了将个人知识库与AI交互相结合的潜力。

在小说创作领域，维基深入收录了多个核心叙事概念：**负面价值三层次**（区分平庸与辉煌的进阶理论）、**正负情感交替**（主动管理读者情感体验的技巧）、**激励事件**（故事真正开始的标志）、**幕结构**（构建故事骨架的宏观方法）、**回报递减定理**（解释为何需要情感交替的原理）、**冲突法则**（无冲突无进展的核心法则），以及**危机场景**（展现人物本性的高光时刻）。这些概念与小说拆解框架和小说创作方法论共同构成完整的“分析-创作”闭环。

最新引入的**AI小说创作三步法**进一步丰富了创作方法论。该方法由角色dna档案、情绪节拍和分层投喂三个核心步骤组成，提供了一套系统化的AI协作创作流程。角色DNA档案为角色构建深层背景，解决AI生成角色扁平化的问题；情绪节拍用读者情绪类型和强度规划故事，替代传统情节大纲，主动管理读者情感体验；分层投喂则通过分批次、分模块地向AI提供写作素材，优化AI的消化和应用效果。这三步法是对ai交互方法论的具体化和深化，也是对正负情感交替理论的实践应用，同时挑战了传统大纲的默认价值。

维基最新收录了**小白爽文创作公式**，这是一套面向网文新手的极简创作方法论。其核心公式为：一个“有毛病”的主角 + 一个“可以摸索”的世界规则 + 一个“出人意料”的真实身份 + 一个“让他坚持到底”的情感理由 = 好看的故事。该公式包含三个核心概念：**主角的“歪”设定**（主角在故事开始时被嘲笑的独特缺点）、**隐藏规则与钻空子**（主角通过发现和利用世界隐藏规则实现非传统成长），以及**大反转**（故事结尾的惊人身份揭示）。这套公式是对小说创作方法论和小说创作方法论的具体化、工具化补充，降低了创作门槛，但主要适用于“爽文”、“系统文”、“游戏异界文”等特定类型。其“自检清单”可以看作是情绪节拍的一种极简、可操作版本。

维基最新收录了**小白写小说核心步骤**，这是一套极简的、步骤化的小说创作流程，共9个步骤：定主题、设激励事件、写大纲、写细纲、加冲突、造反派、写危机、交替情感、扣主题。该流程将维基中已有的多个概念（如激励事件、幕结构、冲突法则、危机场景、正负情感交替）整合成一个线性、可执行的流程，并引入了定主题、造反派和写细纲三个新概念。本文是维基中小说创作方法论和小白爽文创作公式的极简入门版，适合作为新手的第一步。同时，本文与小白爽文创作公式形成互补关系：前者是通用创作流程，后者是特定类型（爽文）的创作公式。

维基最新收录了**小说创作·极简笔记**，这是一份高度浓缩的创作方法论清单，涵盖创作前构思、结构搭建、情节设计、人物塑造、高潮处理和创作心态六大板块。该笔记提出了多个精炼的创作原则：**五问定雏形**（通过五个核心问题快速构建故事雏形）、**先定头尾再连脊椎**（先确定激励事件和高潮对决，再规划中间情节）、**转折点公式**（转折点=期望≠结果）、**压力揭示本性选择定义人格**（角色在压力下展现真实本性，在两难选择中定义人格），以及**起承转合加意外**（在传统结构中加入意外元素）。这份笔记是对维基中小说创作方法论、小白写小说核心步骤和小白爽文创作公式的极简补充，适合作为创作时的快速参考清单。

维基最新收录了**小说架构问卷**，这是一份系统化的小说构思工具，通过24个结构化问题，引导创作者从主题到情感节奏，层层递进地完成故事构思。该问卷整合了维基中多个核心创作概念（如定主题、五问定雏形、激励事件、先定头尾再连脊椎、造反派、危机场景、正负情感交替、写细纲等），形成一个可执行的、顺序化的构思蓝图。它并非提出新理论，而是对现有维基知识的**系统化整合**，是“从知道到做到”的关键桥梁。该问卷可作为小说创作方法论的核心组成部分，也可作为小白写小说核心步骤的深化工具，同时可与小说创作方法论结合，形成“AI辅助构思问卷”。

维基最新收录了**小说框架**，这是一套极简、线性、可操作的小说创作六步流程。该流程从主题出发，经过雏形构思、激励事件设定、结构搭建、场景细化，最终落脚于关键危机，为新手创作者提供了一个完整的创作脚手架。该六步法是对小白写小说核心步骤的补充和深化，两者都是极简创作流程，但六步法更强调“五问定雏形”和“关键危机”，而小白步骤更强调“造反派”和“情感交替”。六步法也是小说创作方法论的具体化工具，适合作为新手入门的第一步。

维基最新收录了**小说描写词汇库**和**语言描写短语**概念，这是一份面向小说写作者的实用素材集合，专注于语言描写。该词汇库按情感色彩和表达效果将描写人物说话方式的短语分为四类：生动简练、笨嘴拙舌、恶语伤人和能说会道。它填补了从“知道怎么写”到“具体怎么写”之间的鸿沟，为维基中已有的创作方法论（如小说创作·极简笔记、小白写小说核心步骤、小白爽文创作公式）提供了底层的、可直接套用的执行工具。该词汇库强调“贴切胜于华丽”、“避免堆砌”、“服务于人物”等使用原则，并鼓励作者理解比喻逻辑后创造自己的独特表达。

维基最新收录了**原创小说·极简精华笔记**，这是“小白从零写小说”系列的核心心法总结。它提供了一个高度浓缩、系统化的成长故事创作公式：**有缺陷的主角 + 可探索的规则体系 + 颠覆性身份真相 + 高维力量干预 + 坚实情感内核 = 好的成长故事**。该笔记将维基中多个分散的概念（如主角的歪设定、规则高于蛮力、冲突法则、定主题）整合成一个有机的创作蓝图，并引入了颠覆性身份真相、高维力量干预、约定与守护、缺陷即特色、规则高于蛮力、冲突法则和自检清单等新概念。这份笔记是对维基中小白爽文创作公式的深化和升华，从“三句话公式”升级为“五大要素公式”，提供了更系统、更完整的创作心法。它与小说创作·极简笔记形成互补：后者是创作流程的清单，前者是创作心法的总结。

维基最新收录了**闲鱼副业**领域，这是一套面向零基础新手的闲鱼电商操作指南。其核心理论是**销量公式**（销量 = 曝光 × 转化率），所有操作围绕“讨好平台获取曝光”和“讨好买家提升转化率”展开。该领域包含多个核心概念：**信息差搬运工**（从拼多多/1688搬运商品到闲鱼赚取差价的商业模式）、**小白黄金选品法**（通过搜索热门关键词和查看“想要数”快速找到有需求的商品）、**补单**（通过模拟真实交易快速提升商品权重和曝光的手段，但存在违规风险）、**闲鱼商品页面优化**（通过优化标题、头图、文案、价格等提升转化率的方法），以及**闲鱼运营避坑指南**（汇总常见错误、违规风险和应对策略）。这套方法论是对维基知识边界的扩展，从“阅读方法”、“创作方法”和“AI交互”延伸到了“副业赚钱”领域。

维基最新收录了**审美设计**领域，这是一套基于《1黑白正负形的图形概括解析力》的构图美学理论。其核心概念是**黑白正负形**——画面中由黑白（或深浅）色块构成的图形关系，黑色区域为“正形”，白色区域为“负形”，两者相互依存、相互界定。该理论认为黑白正负形是画面构图的核心基石，其排布的精妙程度直接决定画面的视觉高度。该领域包含多个核心概念：**图形概括解析力**（将复杂画面简化为基础几何图形以分析构图的能力）、**正负形反转**（打破常规正负形模式以提升构图趣味性的进阶技巧）、**主题置换**（提炼优秀作品的正负形结构应用于不同主题的创作方法），以及**PS色调分离工具**（分析构图的辅助工具）。这套方法论为维基增加了全新的“审美/设计”维度，其“先定框架再填内容”的创作思路与小说创作中的先定头尾再连脊椎有异曲同工之妙，为跨领域知识连接提供了可能。

维基最新收录了**闲鱼店群运营**领域，这是对闲鱼副业的深化和扩展。基于《1闲鱼店群运营细则：从流量获取到转化提升的全流程指南》，该领域以**销量公式（销量 = 流量 × 客单价 × 转化率）** 为唯一主线，系统阐述了从单店运营到多店铺管理的进阶策略。该领域引入了多个新概念：**APDC循环**（制定→执行→测试→优化的营销策略迭代方法论）、**概念营销**（结合社会热点或用户需求场景进行产品包装）、**链接生命周期管理**（管理商品链接从创建、维护到下架的全过程），以及**发布地选择**（根据用户分布选择商品发布地理位置以提升流量精准度）。这些新概念与维基中已有的销量公式、闲鱼商品页面优化、闲鱼运营避坑指南等页面形成互补，共同构建了从单店入门到店群进阶的完整知识体系。该领域强调科学运营方法论和数据驱动决策，同时提醒注意图片版权、违禁词、账号安全等风险。

维基最新收录了**视觉引导**知识体系，这是对审美设计领域的深化和扩展。基于《2视觉引导很重要性.md》，该体系将**视觉引导**确立为构图的底层构成之一，与黑白正负形并列。其核心原理是**视觉惯性**——物体自带的引导目光的特性。基于这一原理，创作者可以使用**视觉引导线**（明确的或含蓄的线条）和**视觉组块**（通过元素组合将视线锁定在重点区域）等具体工具来实现对观众视线的控制。这套方法论填补了维基在构图理论上的一个空白，与已有的黑白正负形、图形概括解析力等概念形成互补，共同构建了从“色块构成”到“视线引导”的完整构图分析框架。其“先定框架再填内容”的创作思路与小说创作中的先定头尾再连脊椎有异曲同工之妙，为跨领域知识连接提供了可能。

维基最新收录了**3D建模**领域，这是对审美设计领域的实践应用扩展。基于《3D新人做次世代角色作品》，该领域聚焦于3D新人如何制作次世代角色作品，核心观点是**挑选合适的原画比建模技术本身更重要**。该领域引入了多个新概念：**次世代角色建模**（使用PBR流程制作高精度3D游戏角色模型的标准流程）、**颜色搭配比例**（7:2:1或6:3:1的配色量化原则），以及**原画挑选**（从概念设计图中选择适合3D建模的图的评估标准和方法）。这些新概念与维基中已有的黑白正负形、图形概括解析力、视觉引导等审美概念形成互补，将抽象的美学原则落地到了具体的3D建模工作流中。该领域强调“选原画优先”的原则，为维基增加了“3D美术”这一新的知识维度。

除了拆书方法论、AI交互、小说创作、闲鱼副业、审美设计、闲鱼店群运营、视觉引导和3D建模，维基还涵盖了相关的学习技巧、内容创作和写作技巧等主题。未来计划扩展更多个人成长领域的内容，如习惯养成、目标管理、时间管理等。维基采用结构化的页面类型（实体、概念、源文档、查询、比较、综合）和严格的交叉引用规则，以确保知识的系统性和可追溯性。

维基的长期目标是成为一个动态的、不断演化的个人知识库，帮助用户深化对自我成长的理解，并支持实际的行为改变。通过定期反思和更新，维基将记录用户的成长轨迹，并为未来的决策提供参考。
