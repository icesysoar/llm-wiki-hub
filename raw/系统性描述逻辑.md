# 系统性描述逻辑

系统性描述逻辑（Systematic Description Logic）是指将艺术创作要素拆解为可枚举、可组合的模块（如“9:16竖构图”、“电影级冷色调”、“柔和光影”），并规定其排列顺序，强调“自宏观到微观”的感知规律。

该逻辑是输出格式规范的理论基础：先描述整体构图与视角，再逐步深入到环境、光影、主体、道具、服装、风格，最后总结氛围。这种从宏观到微观的顺序符合人类视觉感知的认知习惯，也便于AI模型逐层解析并生成图像。
