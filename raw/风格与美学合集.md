# Ins风风格指南

## 概述

Ins风（Instagram风格）是一种源自社交媒体的设计风格，特点是简约、干净、注重色彩搭配和几何构图，强调“高级感”和“生活美学”。在AI图像生成中，该风格常与日系小清新风格指南结合使用。

## 核心视觉元素

### 色调

- **主色调**：低饱和度的粉色系、米色系、灰色系

- **调性**：低对比、柔和、明亮

- **色彩搭配**：遵循7:2:1或6:3:1的配色比例

### 构图

- **几何感**：注重线条和形状的秩序感

- **留白**：大量留白，画面干净不拥挤

- **对称与平衡**：追求视觉平衡

### 图形语言

- **形状**：简洁的几何形状（圆形、矩形、曲线）

- **质感**：强调材质质感（如亚麻、陶瓷、木质）

### 道具与场景

- **常见道具**：精装书籍、抽象雕塑、玻璃生态缸、香薰炉、河石

- **场景**：策展式陈列，稀疏却富有深意

- **光线**：柔和漫射的自然光

光线柔和漫射，色调明亮通透。

无人物入镜，无文字干扰。

```

# 日系小清新风格指南

## 概述

日系小清新是一种源自日本的摄影与设计风格，特点是色调明亮、柔和、低对比，画面干净、治愈，常带有生活感和少女感。在AI图像生成中，该风格可以通过具体的视觉元素拆解来实现。

## 核心视觉元素

### 色调

- **主色调**：粉色系（米粉、浅粉、米黄）

- **调性**：低对比、柔和、明亮通透

- **饱和度**：低饱和度，避免鲜艳刺眼

### 构图

- **景深**：浅景深，背景虚化突出主体

- **虚实节奏**：通过清晰与模糊区域形成主次关系

- **视觉引导**：自然引导视线聚焦主体

### 图形语言

- **形状**：圆弧与曲线为主，避免尖锐棱角

- **情感**：传递温柔、治愈、生活感

### 道具与场景

- **常见道具**：多肉绿植、白色陶瓷杯、毛绒挂件、小夜灯

- **场景**：居家环境、咖啡厅、花园等生活化场景

- **光线**：柔和均匀的自然光或暖色灯光

低对比柔和调性，明亮通透。

图形语言以圆弧与曲线为主，传递温柔生活感。

光线柔和均匀，无人物入镜，无文字干扰。

```
