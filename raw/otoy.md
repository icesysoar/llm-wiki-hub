# OTOY

**OTOY** 是一家专注于 GPU 加速渲染技术的公司，以开发 Octane Render 而闻名。Octane Render 是业界首款完全基于 GPU 的无偏、物理正确渲染引擎，广泛应用于影视、建筑可视化、产品设计等领域。

在 Houdini 生态中，OTOY 提供了 Octane Render 的插件接口，使 Houdini 用户能够在其节点化工作流中调用 Octane 的渲染能力。该集成属于 第三方渲染器接口 范畴。
