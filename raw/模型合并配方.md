# 模型合并配方

本页面记录了《AI关键词.md》中用户自定义的Stable Diffusion模型“Dreamland”的合并配方。模型合并（Model Merging / Checkpoint Merging）是将多个不同的Stable Diffusion模型（Checkpoint）按一定权重混合，生成一个具有混合风格的新模型的高级技术。

## Dreamland 模型配方

### 最终模型
`Dreamland_V11`

### 合并步骤

1.  `Dreamland_V1 = __O1__ + realdosmix, 0.1, ckpt`
2.  `Dreamland_V11 = __O2__ + sunshinemix_sunlightmixPruned, 0.1, ckpt`
3.  `Dreamland_V1 = __O3__ + realeldenapocalypse_Analogsexknoll, 0.1, ckpt`
4.  `Dreamland_V11 = __O4__ + abyssorangemix2_Hard, 0.1, ckpt`
5.  `Dreamland_V1 = __O5__ + basilticabyssdream_bad03Ver1, 0.1, ckpt`
6.  `Dreamland_V11 = __O6__ + anyhentai_18, 0.1, ckpt`
7.  `Dreamland_V1 = __O7__ + chilloutmix_NiPrunedFp32Fix, 0.1, ckpt`
8.  `Dreamland_V11 = __O8__ + abyssorangemix3AOM3_aom3a1b, 0.1, ckpt`
9.  `Dreamland_V1 = __O9__ + orangechillmix_v70, 0.1, ckpt`

### 使用的模型（原料）

- `schoolmax25d_11`
- `realdosmix`
- `sunshinemix_sunlightmixPruned`
- `realdeldenapocalypse_Analogsexknoll`
- `abyssorangemix2_Hard`
- `basilticabyssdream_bad03Ver1`
- `anyhentai_18`
- `chilloutmix_NiPrunedFp32Fix`
- `abyssorangemix3AOM3_aom3a1b`
- `orangechillmix_v70`

### 说明

- 配方中的 `__O1__` 到 `__O9__` 是系统变量，代表前一步合并的结果。
- 每个合并步骤的权重均为 `0.1`，表示新加入的模型对最终结果的影响程度。
- 该配方展示了通过多次迭代、逐步混合不同风格模型来创建个性化模型的过程。
