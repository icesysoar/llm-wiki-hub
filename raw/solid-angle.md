# Solid Angle

Solid Angle 是 Arnold 渲染器的原始开发商。该公司由一群计算机图形学专家创立，专注于开发高质量的光线追踪渲染技术。后被 Autodesk 收购，Arnold 成为 Autodesk 旗下的产品。
