# 标准话术库

按疑问类型分类、经过系统整理和动态迭代的回复模板集合，是刻意练习三步曲中“创建模型”步骤的核心产出物，也是闲鱼沟通转化的日常工具。

## 结构与内容建议

### 分类维度
- 按**疑问类型**：正品验证、价格咨询、效果疑问、售后保障、物流查询等。
- 按**沟通阶段**：售前话术、售中话术、售后话术（参见闲鱼沟通话术三阶段）。
- 按**问题紧急程度**：常见问题、疑难问题、投诉问题。

### 模板设计原则
- 基于闲鱼沟通话术五大原则：每条话术应体现好心情、及时、热情、礼貌、专业。
- 预留变量：使用占位符（如“XX”）方便快速替换。
- 提供正反案例：举例说明优化前后的差异。

### 示例条目

**正品验证类**
```
- 用户问：“是全新正品吗？”
- 回复：“亲，绝对全新未拆封官方正品～ 原厂直发，不是二手或闲置，不正包退，钱退给你，产品我不要了！”
```

**价格类**
```
- 用户问：“能再便宜点吗？”
- 回复：“亲，真的少不了啦～ 这个价格已经是跑量价，再低就亏啦，您多多理解呀！如果您收货后满意，给个好评支持一下～”
```
