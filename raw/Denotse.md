# 降噪

- [降噪](https://learn.foundry.com/nuke/14.0/content/reference_guide/filter_nodes/denoise.html?cshid=Denoise2#Denoise)

- [输入和控制](https://learn.foundry.com/nuke/14.0/content/reference_guide/filter_nodes/denoise.html?cshid=Denoise2#InputsandControls)
- [分步指南](https://learn.foundry.com/nuke/14.0/content/reference_guide/filter_nodes/denoise.html?cshid=Denoise2#StepbyStepGuides)
- [视频教程](https://learn.foundry.com/nuke/14.0/content/reference_guide/filter_nodes/denoise.html?cshid=Denoise2#VideoTutorials)

“去噪”节点是从素材中去除噪点或颗粒的有效工具。它使用空间或时间滤波来消除噪声，而不会损失图像质量。

# 输入和控制

|连接类型|连接名称|功能|
|---|---|---|
|输入|运动|用于附加预先计算的运动矢量（如由 VectorGenerator 创建的运动矢量）的可选输入。<br><br>降噪可以在内部生成运动矢量，但连接此输入可能会产生明显更快的结果。|
|噪声|用于附加单独噪声文件的可选输入。如果您正在处理的复杂素材没有方便的噪点区域来分析噪点，则可以使用噪点输入来分析来自其他图像的噪点并将结果应用于您的素材。|
|源|要去噪的图像序列。|

|控件 （UI）|旋钮（脚本）|默认值|功能|
|---|---|---|---|
|降噪选项卡|   |   |   |
|本地显卡|显卡名称|不适用|在启用“**使用 GPU”（如果可用）**时显示用于渲染的 GPU。本地 GPU 显示 在以下情况下**不可用**：<br><br>• 在**首选项**中选择**使用 CPU** 作为**默认闪烁设备**。<br><br>• 在您的系统上找不到合适的 GPU。<br><br>• 无法创建用于在所选 GPU 上进行处理的上下文，例如当 GPU 上没有足够的可用内存时。<br><br>您可以选择其他 GPU（如果可用），方法是导航到**首选项**并从**默认闪烁设备**下拉列表中选择替代方案。<br><br>**注意：** 选择其他GPU需要您重新启动Nuke，然后更改才会生效。|
|使用图形处理器（如果可用）|使用图形用户界面可用|启用|启用后，渲染发生在指定的**本地 GPU**（如果可用）上，而不是在 CPU 上进行。<br><br>**注意：** 在没有本地 GPU 的情况下启用此选项允许每当在具有可用 GPU 的计算机上打开脚本时，脚本都可以在 GPU 上运行。  <br>如果您希望使用 -**-gpu** 选项从命令行渲染，也应该选择此选项。<br><br>请参阅[Nuke 14发行说明，了解有关Nuke](https://learn.foundry.com/nuke/14.0/content/release_notes.html)支持的GPU的更多信息。|
|源|类型|数字|根据您正在使用的素材类型选择胶片或数字。|
|噪声模型|型|调制|选择您正在处理的噪音类型：<br><br>• 恒定 - 如果您正在处理具有大量细节且在黑暗区域中没有太多噪点的电影素材，或者正在处理具有大量细节但在明亮区域没有太多噪点的数字素材，请尝试此操作。<br><br>• 调制 - 在大多数情况下，这是一个不错的选择。|
|提升黑色|lift_blacks|禁用|启用后，图像中的黑色将向白色抬起。如果您的图像包含大量子黑色（值小于 0 的黑色区域），这将特别有用。|
|轮廓|轮廓|不断|选择要使用的降噪配置文件：<br><br>• 恒定 - 让去噪查看分析区域，并在所有强度上去除相同数量的噪声。常量几乎总是一个不错的选择，但如果您发现降噪结果过于平滑，并且调整降噪量和滚降无济于事，则应尝试将其设置为自动。<br><br>• 自动 - 让降噪根据整个轮廓帧自动估计噪声配置文件。这样，“去噪”功能可以从“源”图像的阴影、中间调和高光区域去除不同数量的噪点。首次切换到自动性能分析时，降噪使用当前帧来计算配置文件。如果要使用其他框架，则需要将“配置文件”选项卡上的“配置文件框”设置为该框架，然后单击“重新计算配置文件”按钮。<br><br>Denoise always bases the noise profile on your Source footage, even if you’ve attached another clip to the Noise input.<br><br>可以使用“调整配置文件”控件来调整“常量”和“自动”配置文件。|
|输出|输出|结果|是输出去噪图像还是已去除的噪声：<br><br>• 结果 - 输出去噪的源图像。<br><br>• 噪点 - 输出从源图像中删除的噪点。在此图像中，仅可见噪点。如果您可以看到很多图片细节，则意味着当前设置使降噪工作过于困难并删除了太多图像，从而导致结果柔和。|
|降噪量|量|1|设置要删除的噪声总量。增加此值可消除更多噪点，或减小此值以保留更多细节。值为 0 时不消除噪音。|
|滚落|滚降|2|设置降噪阈值的平滑度。<br><br>值 1 等于硬阈值。任何其他值都会在降噪量和滚降乘以降噪量之间产生软阈值。|
|平滑|平滑|1|设置降噪图像的平滑度。这会影响底层图像，而不是检测到的噪点。<br><br>在大多数情况下，默认值 1 工作正常。但是，如果通过调整降噪量未获得正确的平滑度级别，则可以尝试使用此控件。|
|亮度混合|卢马本|0.7|将去噪亮度与图像的原始亮度混合，在结果中恢复一些图像细节。<br><br>当您对素材进行降噪时，您可能希望将其设置为 1，但对于最终结果，您需要将其减小。|
|保留边缘|preserve_edges|禁用|启用后，去噪会尝试锐化边缘处的图像以防止过度平滑，但在某些情况下这可能会强调噪点。|
|时间处理|   |   |   |
|使|enable_temporal|禁用|启用后，使用当前帧的任一侧的帧来执行临时帧混合，这可能会产生更好的降噪结果。<br><br>**注意：** 必须连接**运动**输入才能启用**时态处理**。<br><br>当前帧两侧使用的帧数由**“时态帧偏移**”控件确定。<br><br>禁用时，仅使用当前帧生成降噪结果。|
|帧混合|frame_blending|0.1|设置混合帧中各条区之间允许的差异。较高的值会尝试混合更多区域，但可能会丢失图像细节。<br><br>**注意：**  仅当启用**临时处理**时，此控件才可用。|
|要混合的帧|框架|1|设置当前帧两侧用于计算降噪效果的帧数。<br><br>**注意：** 仅当启用**临时处理**时，此控件才可用。|
|噪声分析|   |   |   |
|锁定噪声分析|锁噪声分析|禁用|启用后，不执行任何分析。如果使用“导入”按钮从外部文件中读取噪声配置文件，则默认情况下会激活此功能。|
|分析区域|分析区域|不适用|输入要分析噪声的区域的坐标。<br><br>您可以调整以下内容：<br><br>• x - 图像左边缘与分析框左侧之间的距离（以像素为单位）。<br><br>• y - 图像的底边缘和分析框的下边缘之间的距离（以像素为单位）。<br><br>• r - 图像左边缘与分析框右侧之间的距离（以像素为单位）。<br><br>• t - 图像的底部边缘和分析框的顶部边缘之间的距离（以像素为单位）。<br><br>• w - 分析框的宽度。这仅在您单击 wh 按钮时才可用。<br><br>• h - 分析框的高度。这仅在您单击 wh 按钮时才可用。<br><br>您还可以使用查看器中的分析框来定位分析区域。这应该是一个没有图像细节的平面区域，因此没有纹理、边缘或阴影。分析区域的最小大小为 80x80 像素。如果分析区域太小，降噪不会分析素材或去除任何噪点。<br><br>默认情况下，每当更改分析框时，都会重新对该区域中的噪声进行内部分析。|
|分析框架|分析框架|1|用于分析分析区域中噪声的帧。<br><br>如果在查看器中拖动到新帧并重新定位分析框，则此字段将自动更新。|
|分析噪声|分析|不适用|单击此按钮可分析素材中的噪点。如果您擦洗到新帧，不移动分析框，并且想要重新分析来自新帧的噪声，这会很有用。|
|分析文件|分析文件|不适用|外部分析文件的名称和位置。单击“导出”按钮将分析配置文件保存在此文件中，或单击“导入”从此文件中读取分析配置文件。<br><br>分析文件可以是任何二进制文件 - 例如纯文本文件 （.txt）。|
|进口|进口|不适用|从外部分析文件（在分析文件中指定）读取分析配置文件。这将禁用从分析文件中读取的任何控件。要重新启用它们，您可以取消选中锁定噪声分析。|
|出口|出口|不适用|将分析配置文件保存到外部分析文件（在分析文件中指定）。<br><br>**注意：** 如果已将“配置文件”设置为“常量”，则只有影响分析的控件才会保存在此文件中。相反，如果将“配置文件”设置为“自动”，则会导出分析配置文件和自动计算的噪声配置文件。|
|调谐频率|   |   |   |
|处理高频|进程高|启用|如果要消除高频中的噪声（精细细节），请启用此选项。|
|高增益|高金额|1|缩放精细噪声消除的阈值。<br><br>增大此值可消除更多精细噪点，或减小此值可保留更多细节和细噪点。值为 0 表示未消除精细噪声，而 1 表示估计阈值。|
|工艺介质频率|过程介质|启用|如果要消除中频中的噪声，请启用此选项。|
|中等增益|中等量|1|缩放中等噪声消除的阈值。<br><br>增大此值可去除更多中等噪点，或减小此值可保留更多细节和中等噪点。值为 0 表示未消除中等噪声，而 1 表示估计阈值。|
|处理低频|进程低|启用|如果要消除低频中的噪声（粗略细节），请启用此选项。<br><br>通常，大多数噪声发生在高频和中频，因此通常可以完全禁用低频。|
|低增益|低金额|1|缩放低噪声消除的阈值。<br><br>增大此值可去除更多低噪点，或减小此值可保留更多细节和低噪点。值为 0 表示未去除低噪声，而 1 表示估计阈值。|
|处理极低频率|进程非常低|禁用|如果要消除非常低频率的噪声（非常粗糙的细节），请启用此选项。<br><br>通常，大多数噪声发生在高频和中频，因此通常您可以完全禁用非常低的频率。|
|极低增益|非常低的金额|1|缩放极低噪声消除的阈值。<br><br>增大此值可去除更多非常低的噪点，或减小此值可保留更多细节和非常低的噪点。值为 0 表示没有去除非常低的噪声，而 1 是估计的阈值。|
|调谐频道|   |   |   |
|亮度增益|亮度金额|1|缩放亮度通道的去噪阈值。增大此值可消除更多杂色，或减小此值可保留更多细节和杂色。|
|色度增益|色度金额|5|缩放色度通道的去噪阈值。增大此值可消除更多杂色，或减小此值可保留更多细节和杂色。|
|“配置文件”选项卡|   |   |   |
|曲线编辑器|配置文件曲线|不适用|噪声分布曲线。x 轴表示图像强度，从左侧的黑暗区域到右侧的较亮区域。y 轴表示去除的相对噪声量。<br><br>您可以通过将曲线上的点拖动到新位置来手动调整曲线。要向曲线添加更多点，请按 Ctrl/Cmd+Alt+单击曲线。<br><br>如果您对更改不满意，请单击“重置轮廓”将曲线重置为其原始形状。|
|重置|不适用|不适用|重置对噪声曲线所做的任何更改。这不会影响使用低增益、中增益和高增益控件所做的更改。<br><br>此按钮的功能与下面的“重置配置文件”按钮相同。|
|调谐配置文件|调谐配置文件|禁用|启用此选项可通过调整低增益、中增益或高增益来调整噪声配置文件。这在常量和自动分析模式下都有效。|
|低增益|低增益|1|缩放源图像的低光区域中的去噪阈值。例如，值 2 将阈值乘以 2。低于阈值的所有内容都被视为噪声并被删除，而高于阈值的所有内容都将保留。<br><br>此控件仅在启用“调整配置文件”时可用。|
|中等增益|中增益|1|缩放源图像中间调区域中的去噪阈值。例如，值 2 将阈值乘以 2。低于阈值的所有内容都被视为噪声并被删除，而高于阈值的所有内容都将保留。<br><br>此控件仅在启用“调整配置文件”时可用。|
|高增益|高增益|1|缩放源图像高亮区域中的去噪阈值。例如，值 2 将阈值乘以 2。低于阈值的所有内容都被视为噪声并被删除，而高于阈值的所有内容都将保留。<br><br>此控件仅在启用“调整配置文件”时可用。|
|轮廓框架|配置文件框架|1|当“配置文件”设置为“自动”时估计噪声配置文件的帧。<br><br>此控件是只读的。如果要更改配置文件框架，则需要在查看器中清理到新框架，然后单击重新计算配置文件。|
|重新计算配置文件|重新剖析|不适用|如果已将“配置文件”设置为“自动”，则降噪首先使用当前帧来计算配置文件。如果要使用其他框架，则需要擦洗到该框架并单击此按钮。|
