# 补偿机制

底层角色必须具备的特殊能力或知识，用以弥补行动力弱的缺陷，推动剧情发展。这是**底层视角叙事**成立的前提。

## 定义

在主角处于社会最底层、行动力受限的情况下，必须赋予其某种特殊的"补偿"，使其能够：
1. 获取信息（而非被动等待）。
2. 解决危机（而非单纯挨打）。
3. 推动故事（而非停滞不前）。

## 核心公式

```
补偿机制 = 特殊能力/知识 + 弥补行动力缺陷 + 推动剧情
```

## 典型示例

### 猫猫（《药屋少女的呢喃》）
- **缺陷**：社会地位最低（下女），外貌被嘲笑（雀斑、枯枝手脚）。
- **补偿**：药师知识。
- **作用**：看穿所有人的"毒"，通过衣物上的线索推断全局，成为连接底层与核心事件的关键。

### 程肖宇（《我独自升级》）
- **缺陷**：E 级猎人标签，被嘲笑为最弱。
- **补偿**：超灵敏听觉。
- **作用**：被动听到别人不敢说的信息，提前预警危机，弥补无法主动出击的劣势。

## 设计原则

1. **必要性**：没有补偿机制，底层视角无法成立，主角会沦为旁观者。
2. **隐蔽性**：补偿机制往往被外界忽视（如听觉、知识），形成信息差。
3. **成长性**：补偿机制可以随着剧情发展而升级或扩展。
4. **关联性**：补偿机制应与**冲突法则**中的社会性冲突紧密相关。

## 关联概念

- 底层视角叙事：补偿机制是其核心公式的一部分。
- 主角设计原则：缺陷 + 补偿是主角成长的基础。
- 缺陷即特色：主角的起点是一个被嘲笑的缺陷，这个缺陷恰恰是其独特优势和故事特色的来源。
- 被动知情：利用补偿机制获取信息的一种特殊手段。
