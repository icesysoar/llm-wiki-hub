# 销售漏斗

销售漏斗是闲鱼运营中用于诊断和优化转化率问题的核心分析框架与底层逻辑模型。它将用户从看到商品到最终下单的完整路径拆解为多个环节，每个环节都存在用户流失，帮助卖家定位问题并针对性优化。

## 核心结构

销售漏斗的典型结构为：**曝光 → 点击 → 想要 → 咨询 → 下单**。越到下层，用户数量越少，需要层层优化。

## 各环节详解

### 1. 曝光
- **场景**：用户搜索关键词后，商品链接出现在搜索结果页。
- **核心问题**：用户会选择哪家点击？

### 2. 点击（浏览）
- **核心影响因素**：主图（清晰实拍图）、价格（有竞争力）、“想要”数（信任背书）、包邮、标题、好评/发布时间、发布地。
- **关键指标**：曝光点击率 = 点击人数 ÷ 曝光人数。
- **优化技巧**：使用低价引流策略策略（如二手伪装法、配件拆分法）提升点击率。
- **常见问题**：主图模糊、标题不精准、价格缺乏竞争力。

### 3. 想要
- **用户选择**：直接下单、点击“我想要”咨询、退出/换店。
- **核心影响因素**：详情页文案（打消正品、售后疑虑）、配图（多角度清晰展示）、账号信用、店铺搭建、数据喂养、好评留言。
- **关键逻辑**：文案需打消用户疑虑，配图需清晰多角度展示。

### 4. 咨询和成交
- **关键指标**：咨询转化率 = 成交单数 ÷ 咨询人数。
- **核心影响因素**：响应速度（30秒内回复）、话术技巧（遵循热情原则）、信任背书（店铺专业度、信用分、好评率）。
- **常见问题**：回复慢、话术生硬、缺乏信任背书。

## 优化原则

1. **优先解决最薄弱环节**：找出漏斗中流失最严重的环节，优先优化。
2. **从上到下逐级优化**：先优化曝光点击率，再优化咨询转化率，层层推进。
3. **数据驱动决策**：通过各环节的转化率数据判断问题所在。

## 常见问题排查

- **高曝光低点击**：优化主图/标题，解决流量不精准问题。
- **高点击低咨询**：调整价格/详情页文案。
- **高咨询低成交**：提升客服话术和响应速度。

## 案例对比

- 2万曝光 → 1%点击率（200人点击）→ 100%咨询转化 = 200单
- 2万曝光 → 10%点击率（2000人点击）→ 20%咨询转化 = 400单

## 与现有概念的关系

- 销量公式：销售漏斗是对“转化率”的精细化拆解，提供了可操作的分析框架。
- 闲鱼商品页面优化：销售漏斗中的“点击”和“想要”环节直接对应商品页面的优化。
- 闲鱼沟通五大原则：销售漏斗中的“咨询”环节对应客服沟通技巧。
- 补单：补单可以提升“我想要”数量，从而提升点击率。
- 标签匹配机制：与销售漏斗共同构成了闲鱼运营的底层逻辑框架。
- 闲鱼店群运营：销售漏斗为闲鱼店群运营提供了诊断转化率问题的分析工具。
