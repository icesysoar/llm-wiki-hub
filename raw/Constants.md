# Constant 

生成每个像素都是相同颜色的图像。这包括图像区域外部和内部的像素。

# 输入和控制

|控件 （UI）|旋钮（脚本）|默认值|功能|
|---|---|---|---|
|“常量”选项卡|   |   |   |
|channels|渠道|RGBA|常量仅包含这些通道。<br><br>如果将其设置为“**全部**”或**“无**”以外的其他值，则可以使用右侧的复选框来选择各个频道。|
|color|颜色|0|设置常量的颜色。|
|format|格式|取决于**项目设置**|设置常量的格式。您可以选择预设格式或使用**新建**或**编辑**选项创建自定义大小。|
|frame range|第一|1|如果要对常量进行动画处理， 设置包含动画的帧范围。|
|最后|1|
